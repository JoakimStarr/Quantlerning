# Quantlerning · 一本书计划（Book Plan）

> 目标：把 Quantlerning 做成**一本可以交互式的、可视化的一本书**——不是「学习网站」，而是一本读者能从头读到尾、边读边动手、图随文动、越读越懂的书。
> 制定日期：2026-08-17

---

## 1. 一本书应该有什么

「书」的体验 = 结构感 + 阅读感 + 内容厚度 + 图与文的融合。

| 书的要素 | 书里的形态 | Quantlerning 现状 |
|---|---|---|
| 封面 | 首页第一眼、书名、作者 | ✗ 首页是学习地图，无封面 |
| 序/导读 | 「这本书怎么读」「适合谁」 | ✗ 无作者序 |
| 目录 | 卷→章→节，可跳转 | ✓ 侧栏三级目录 |
| 正文 | 章节、小节、图文交融 | ✓ 12.5k 行 md + 74 viz 组件 |
| 图 | 插图 + 图注 + 「看懂什么」 | ✓ 嵌入正文，✗ 部分缺图后引导（D1=30） |
| 练习 | 课后题 + 答案 | ✓ quiz/exercise 收进末尾 |
| 术语/索引 | 术语表、概念索引 | ✗ 无 |
| 书签/笔记 | 记住读到哪、划重点 | △ 位置记忆有，无书签/高亮 |
| 结语/后记 | 全书收束 | ✗ 各章有小结，无全书后记 |
| 参考文献 | 每章延伸阅读 | ✓ 已齐 |

## 2. 目标形态（一次读完一本书的体验）

1. **打开首页 = 翻开封面**：书名 + 一句定位 + 「开始阅读」；往下是整本书的「学习地图」（目录）。
2. **进入正文 = 正常读书**：章引言（已有）→ 小节编号（已有）→ 图文交融（已有）→ 章末练习（已有）。
3. **图是「活的插图」**：每个核心图配「先看什么 → 看到什么 → 为什么」三句话引导，读者知道看图要看懂什么。
4. **概念有「索引」**：术语表/概念索引，从「夏普比率」一词能跳到它在全书出现过的所有位置。
5. **进度像「书签」**：记住读到哪一课、哪一小节；每章显示阅读百分比（不只是完成勾选）。
6. **读完有「收束」**：全书结语 + 各章知识点回顾，让读者感到「读完了一本书」。

## 3. 现状盘点

**已有（保持并强化）**：
- 55 课内容（12.5k 行 md）、74 个 viz 组件全部真实实现
- 三层引子（章引言/课引言/导论课）、衔接、概念四步引入
- 正文与练习分离；quiz/exercise 收进章末
- 侧栏三级目录 + 搜索（按标题/概念）+ 展开折叠
- 阅读位置记忆（`ql:lastPath`）+ 浏览器原生滚动恢复
- 主题跟随系统、移动端抽屉目录
- 测验/应用题/沙箱/AI 追问/变式题等交互闭环
- 内容质量检查器（`scripts/check_content.py`）+ P0-P4 修复机制

**缺口（按优先级，见第 4 节）**：
1. 封面页/作者序/全书结语
2. 书签/高亮笔记/字号调节
3. 术语表/概念索引
4. 章阅读百分比（非完成勾选）
5. 正文全文搜索（目前只搜标题/概念）
6. 部分 viz 缺图后引导（D1=30）
7. 内容质量遗留（C2=95 / B1=21 / B2=5）

## 4. 分阶段计划

每阶段独立验收、独立提交。总原则：**先书感外壳，再阅读工具，再知识组织，最后内容收尾**。

### B1 书感外壳（书的骨架感）

| 任务 | 说明 | 涉及文件 |
|---|---|---|
| 首页封面化 | HomeView 顶部改为「封面区」：书名 + 定位语 + 「开始阅读」按钮 + 总进度，保留学习地图在下 | `HomeView.vue` |
| 作者序 | 新增「序」内容（md，phase0 前）：这本书写给谁、怎么读、需要什么基础 | 新 md + `courses.py` 或首页区块 |
| 全书结语 | 新增「后记」内容（md，phase6 后）：六章知识全景 + 下一步方向 | 新 md + `courses.py` 或收尾区块 |
| 章阅读百分比 | 侧栏/Phase 卡显示每章「已读 x%」（按小节完成数/总小节），区别于「已完成」勾选 | `stores/progress.ts`、`App.vue` |

验收：首页有封面感；序/后记可读；侧栏每章显示阅读百分比。

### B2 阅读工具（读得更顺）

| 任务 | 说明 | 涉及文件 |
|---|---|---|
| 书签 | 正文任意位置加书签（`ql:bookmarks`），首页「书签」入口，点击跳回该课该小节 | `LessonView.vue`、`HomeView.vue` |
| 高亮笔记 | 选中文字 → 「高亮」按钮，存 `ql:notes:{lesson}`（文本+小节+颜色），侧栏或课后列表展示 | `LessonView.vue`、`utils/selectionToMarkdown.ts` 旁 |
| 字号调节 | 正文字号 A-/A+ 持久化（`ql:fontScale`），适配移动端 | `LessonView.vue`、全局样式 |
| 正文全文搜索 | 搜索框扩展到正文全文（前端索引 md 内容，或后端加搜索接口），结果带位置跳转 | 侧栏搜索、`MarkdownRenderer` 锚点 |

验收：可加书签/高亮并跳回；字号可调；全文搜索命中正文并跳转。

### B3 知识组织（像书的附录）

| 任务 | 说明 | 涉及文件 |
|---|---|---|
| 术语表 | 从 courses.py 的 concepts + 正文自动抽取术语，生成「术语表」页面：术语 → 定义 → 出现课程列表 | 后端聚合 + `GlossaryView.vue` |
| 概念索引 | 每个概念可点击，展示「在哪几课出现过」（基于 frontmatter concepts 或正文检索），形成全书索引 | `utils/`、`LessonView.vue` |
| 跨课关联 | 基于前置/产出标注（P0 已补）生成「相关课程」区块（前置→本节→后续），替代纯 AI 生成的关联 | `LessonView.vue`、API |

验收：有术语表页；概念可索引跳转；每课底部有结构化「前置/后续」链。

### B4 内容质量收尾（书要经得起读）

沿用 `scripts/check_content.py`，按 P0-P4 机制逐批清零：

| 批次 | 问题 | 数量 | 状态 |
|---|---|---|---|
| P2 | D1 viz 图后引导 | 30 | 待做 |
| P3 | C2 Unicode 公式→LaTeX | 95 | 待做 |
| P4 | B1 正文行数 + B2 薄节 | 21+5 | 待做 |

验收：检查器对应维度归零。

### B5 图的引导强化（图的「看懂什么」）

在 P2 基础上，对**每个核心 viz** 检查「图注 + 图后引导」双齐全（规范已要求）；对重点图（主线策略/因子/定价/组合）补「读图要点」小结块，让图成为真正的插图而非装饰。

验收：74 个 viz 全部有 caption + 图后引导。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 功能开发挤压内容修复 | B1-B3 与 B4/B5 并行：功能是「外壳」，内容是「内核」，两端都做，按阶段提交 |
| 术语表抽取质量 | 先自动抽取 + 人工校对关键词表，宁缺毋滥 |
| 书签/高亮跨版本失效 | 用课 id + 小节 id（`sec-N`）存地址，重构正文不破坏地址 |
| 正文全文搜索性能 | 前端预构建标题+正文索引（约 12.5k 行文本，可接受），或后端一次性全量接口 + 缓存 |

## 6. 验收总则（这本书做完的标志）

1. 首页有封面感，序/后记可读；
2. 侧栏目录有「章阅读百分比」；
3. 可加书签/高亮/调字号，并可靠跳回；
4. 有术语表和概念索引，概念可跳全书位置；
5. 每课底部有结构化前置/后续关联；
6. `check_content.py` 五个维度归零（C1/C2/D1/B1/B2/E1/A1/A2 全通过）；
7. 全书 74 个 viz 均有 caption + 图后引导。
