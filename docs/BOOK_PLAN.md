# Quantlerning · 一本书计划（内容版 Book Plan）

> 目标：把 Quantlerning 的内容本身做成**一本可交互、可演算、可动手的量化书**——结构完整、前后贯通、图文交融、经得起逐字读。
> 制定日期：2026-08-17（v2，聚焦内容，UI 外壳暂缓）

---

## 1. 内容层面「一本书」缺什么

「书感」的内容 = 结构性内容（章引言/序/结语）+ 内容质量（检查器清零）+ 图文融合（图引导）+ 知识组织（术语/索引/关联）。

| 书的要素 | 书里的形态 | 内容现状 |
|---|---|---|
| 章引言 | 每章开头一段「本章讲什么、在全书的位置」 | ✗ **5/7 阶段缺 intro**（phase0/3/4/5/6） |
| 作者序 | 「这本书写给谁、怎么读、需要什么基础」 | ✗ 无 |
| 全书结语 | 六章知识全景 + 读完能做什么 | ✗ 无（各章小结有，全书无后记） |
| 正文深度 | 每章内容厚度与讲解充分度 | △ B1=21 课 <100 行、B2=5 薄节 |
| 图与文的融合 | 每个图有 caption + 图后「看懂什么」引导 | △ D1=30 图缺引导 |
| 专业度 | 公式统一 LaTeX、术语准确 | △ C2=95 处 Unicode 公式符号 |
| 术语/索引 | 术语表、概念索引、跨课关联 | ✗ 无 |
| 参考文献 | 每章延伸阅读 | ✓ 已齐 |
| 练习 | 课后题、测验 | ✓ 已齐 |

**核心结论**：内容书感的最大缺口是「**章引言 5 缺 + 序/结语无**」——读者打开一章不知道它讲什么、为什么在书里这个位置；读完全书没有收束感。

## 2. 目标形态（内容层面的书感）

1. **打开每一章**：有章引言（phase0 前言、phase1-6 各章各一段）——「上一章讲了什么、这一章讲什么、章内逻辑线、学完能做什么」。
2. **翻开书**：有作者序——写给谁、怎么读、需要什么基础、全书结构地图。
3. **合上书**：有全书结语——六章知识全景回顾 + 读完能做什么 + 下一步方向。
4. **每一段图**：caption + 图后「先看什么 → 看到什么 → 为什么」双齐全，图是活插图而非装饰。
5. **每一处公式**：统一 LaTeX，无 Unicode 公式符号，读起来专业。
6. **概念可索引**：术语表 + 概念索引，从「夏普比率」能跳到全书所有出现处。

## 4. 分阶段计划（内容）

每阶段独立验收、独立提交。

### C1 章引言补全（最大书感缺口，成本低）

为 5 个缺 intro 的阶段各写一段章引言（写进 `courses.py` 的 `intro` 字段，PhaseView 已支持渲染）：
- **phase0**：前言——为什么先学数学/编程，前言在全书的位置，学完能做什么
- **phase3**：因子投资——从「策略」到「因子」的视角切换，章内逻辑线（因子→检验→合成→风险模型→产出）
- **phase4**：衍生品——为什么单靠股票不够，随机过程→定价→Greeks→VaR 的路径
- **phase5**：机器学习——从规则策略到数据定规则，特征→标签→模型→评估→产出
- **phase6**：组合与实盘——从单标的到组合、从回测到实盘，全书收束章

每段 3-5 句：上一章的位置 → 本章讲什么 → 章内逻辑线 → 学完能做什么。风格对齐 phase1/2 已有 intro。

验收：7 个阶段 intro 全覆盖，`get_content()` 返回正常。

### C2 序与结语（书的封面/合卷感）

| 任务 | 说明 |
|---|---|
| 作者序 | 新增 `phase0` 前置内容（或首页文本块）：写给谁、怎么读（先通读后精读）、需要什么基础、全书 6 章结构地图、与前言的衔接 |
| 全书结语 | 新增 `phase6` 后记内容：六章知识全景回顾（数据→策略→因子→衍生品→ML→组合实盘）、读完能做什么、下一步方向（实盘/论文/竞赛）、与「模型有用≠策略赚钱」的呼应 |

验收：序与结语内容可读，与章节衔接自然。

### C3 术语表与概念索引（书的附录）

- 从 courses.py 的 `concepts` 字段 + 正文抽取术语，生成**术语表**：术语 → 一句话定义 → 出现课程列表（前端 `GlossaryView.vue` 或内容生成）
- **概念索引**：每个概念可点击，展示「在哪几课出现过」（基于 frontmatter concepts 或正文检索）
- **跨课关联**：基于前置/产出标注（P0 已补）生成「相关课程」链（前置→本节→后续）

验收：术语表页可访问；概念可索引跳转；每课底部有结构化前置/后续链。

### C4 内容质量收尾（经得起逐字读）

沿用 `scripts/check_content.py`，按 P0-P4 机制逐批清零：

| 批次 | 问题 | 数量 |
|---|---|---|
| P2 | D1 viz 图后引导 | 30 |
| P3 | C2 Unicode 公式→LaTeX | 95 |
| P4 | B1 正文行数 + B2 薄节 | 21+5 |

验收：检查器对应维度归零（当前全书 151 项 → 目标 0）。

### C5 图文融合强化（图是活插图）

在 P2 基础上，对每个核心 viz 检查「caption + 图后引导」双齐全（规范已要求）；对重点图（主线策略/因子/定价/组合/ML）补「读图要点」小结块。

验收：74 个 viz 全部有 caption + 图后引导，检查器 D1=0。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
