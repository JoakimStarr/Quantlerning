> **学完能做什么：** 全书任何位置遇到术语卡壳时，30 秒内找回定义与出处。

## 使用方式

词条按主题分组（不是字母序——量化的术语天然按主题聚簇）。每条格式：**术语**：一句话定义。→ 详解课号。第一次学到某词条时不必背，读到后面忘了再回来。

## 金融市场与利率

- **T+1**：当天买入的股票下一交易日才能卖出。→ p1-l1
- **涨跌停**：单日价格波动区间限制（主板 ±10%、创/科 ±20%）。→ p1-l1
- **除权除息**：分红送股后价格机械下调，账户总财富不变。→ p1-l1
- **复权**：调整历史价格使除权日可比，量化收益计算统一用复权口径。→ p1-l2
- **现值 PV / 终值 FV**：未来一笔钱折算到今天 / 今天一笔钱滚到未来。→ p1-l3
- **IRR**：使 NPV=0 的折现率，项目自身的真实回报率。→ p1-l3
- **久期 / 修正久期**：债券价格对利率的敏感度（加权平均回款时间）/ 除以 (1+y) 后的精确版。→ p1-l4
- **凸性**：价格-收益率曲线的二阶曲率，恒为正 → 债券「涨多跌少」。→ p1-l4
- **收益率曲线 / 期限利差**：不同期限国债收益率的连线 / 长端减短端（如 10Y−2Y）。→ p1-l3
- **风险溢价**：$E[R]-r_f$，承担风险要求的额外补偿。→ p1-l3

## 估值与基本面

- **DCF / DDM**：现金流折现估值 / 股利折现模型。→ p1-l5
- **WACC**：加权平均资本成本，DCF 的折现率。→ p2-l4
- **终值 TV**：显式预测期之后全部价值的打包，常占 DCF 的 60-80%。→ p2-l4
- **PE / PB / PS**：市值÷净利润 / 净资产 / 营收——盈利稳用 PE、资产重用 PB、没利润用 PS。→ p2-l5
- **PEG**：PE÷盈利增速，<1 视为增长未被完全定价。→ p2-l5
- **杜邦分解**：ROE = 净利率 × 周转率 × 权益乘数。→ p2-l2
- **净现比**：经营现金流÷净利润，利润含金量的标尺。→ p2-l3
- **扣非净利**：剔除一次性损益后的利润，衡量可持续盈利。→ p2-l3
- **护城河**：竞争者抢不走高盈利的可防守优势（品牌/转换成本/网络效应/成本）。→ p2-l6

## 统计与检验

- **标准误 SE**：样本统计量的标准差，$\sigma/\sqrt n$——堆数据压误差的代价是平方根。→ p0-l2
- **置信区间**：重复抽样约 95% 覆盖真值的区间（参数固定、区间随机）。→ p0-l2
- **p 值**：$H_0$ 成立下观察到当前或更极端数据的概率；p<α 拒绝 $H_0$。→ p0-l2
- **第一/二类错误**：假阳性（真 $H_0$ 被拒）/ 漏检（假 $H_0$ 未拒）。→ p0-l2
- **平稳性 / 单位根 / ADF**：均值方差不随时间变 / 非平稳的数学刻画 / 检验它们的统计方法。→ p0-l5
- **协整**：两个非平稳序列的（回归）残差平稳——价差会回归，配对交易的前提。→ p7-l2
- **伪回归**：对无关的非平稳序列回归得到「显著相关」的假象。→ p0-l5
- **多重检验**：试验次数越多，最优结果越可能是运气；校正用 Bonferroni（α/N）。→ p3-l5

## 策略与回测

- **信号 → 持仓 → 交易**：策略三段式（方向判断 → 仓位映射 → 落地成交）。→ p3-l1
- **金叉/死叉**：快线上穿/下穿慢线。→ p3-l2
- **唐奇安通道**：突破过去 N 日最高价进场、跌破 M 日最低价离场（海龟核心）。→ p3-l2
- **布林带 / z-score**：均线 ±k 倍标准差 / 价格偏离均值的标准化倍数。→ p3-l3
- **时序/横截面动量**：看自己过去 N 日涨跌 / 同类之间比相对强弱。→ p3-l4
- **前视偏差**：把未来信息混进历史决策（当日收盘信号当日成交）。→ p3-l5
- **幸存者偏差**：只用今天还存活的名单回测历史，天然偏乐观。→ p3-l5
- **过拟合**：参数把历史噪声当规律；锯齿/山峰型参数平面是它的画像。→ p3-l5
- **夏普 / Sortino / Calmar**：超额÷总波动 / ÷下行波动 / 年化÷最大回撤。→ p3-l6
- **水下期间**：净值低于历史峰值的持续时长——「套多久」。→ p3-l6
- **信息比率 IR**：超额收益÷跟踪误差，评价相对基准的增强能力。→ p3-l6
- **换手率**：交易金额÷持仓市值，成本敏感性的放大器。→ p3-l7

## 因子与组合

- **因子暴露 β / 因子溢价 λ**：股票属于哪类（可测）/ 该类的期望超额收益（需估计）。→ p4-l1
- **IC / Rank IC / ICIR**：因子值与未来收益的相关 / 排秩后相关（更稳健）/ IC 的稳定性（>0.3 算稳）。→ p4-l3
- **分层收益**：按因子值分 5 组比较未来收益，看单调性。→ p4-l3
- **中性化**：剥离行业/市值的影响，留下因子自身信息（回归取残差）。→ p4-l4
- **因子拥挤**：资金同质化交易把 alpha 买掉；换手/相关性/负偏是温度计。→ p4-l5
- **Barra 归因**：把收益拆成行业 + 风格 + 选股残差，区分 β 与 α。→ p4-l6
- **有效前沿 / 最小方差组合**：风险-收益平面的左上包络 / 前沿上风险最低点。→ p7-l1
- **风险平价**：让每个资产的风险贡献相等（不预测收益）。→ p7-l1
- **Black-Litterman**：从均衡权重反推隐含收益，再把主观观点按置信度融入。→ p7-l1

## 衍生品与风控

- **布朗运动 / GBM**：增量独立正态、路径连续不可导的随机过程 / 加漂移与比例波动的股价模型。→ p5-l1
- **伊藤引理**：随机函数的链式法则，多出的 $\frac12\sigma^2S^2f''$ 项是期权时间价值的来源。→ p5-l1
- **波动拖累**：对数漂移比算术漂移小 $\sigma^2/2$——波动率平方级侵蚀复利。→ p5-l1
- **风险中性定价**：用无套利（而非真实）概率取期望折现，定价不依赖 $\mu$。→ p5-l2
- **BS 公式**：欧式期权解析解，$C=S_0N(d_1)-Ke^{-rT}N(d_2)$。→ p5-l2
- **Greeks（Δ/Γ/ν/Θ/ρ）**：期权价格对标的价格/二阶/波动率/时间/利率的敏感度。→ p5-l4
- **Delta 对冲**：持有 Δ 份标的抵消方向风险；对冲后「赚 Gamma、亏 Theta」。→ p5-l4
- **隐含波动率 / 波动率微笑**：市场价反解出的 σ / 不同行权价 IV 的系统性形态。→ p5-l5
- **VaR / CVaR**：给定置信度的最大预期损失 / 超过 VaR 部分的条件平均（满足次可加性）。→ p5-l6
- **订单簿 / 价差 / 深度 / 滑点**：买卖挂单排队 / 买卖一价之差 / 各价位挂单量 / 实际成交偏离理想价。→ p7-l5
- **模拟盘**：真实行情 + 虚拟资金的全链路演练，验证「跑得通」而非「能赚钱」。→ p7-l4

## 机器学习量化

- **特征 = 因子**：ML 的输入特征在量化里就是因子（时间对齐纪律相同）。→ p6-l2
- **标签**：监督学习的预测目标（前瞻 h 日收益与阈值 θ 比较的二值化）。→ p6-l3
- **类别不平衡**：多数类占比过高 → 模型「永远猜多数类」拿虚高准确率。→ p6-l3
- **偏差-方差权衡**：总误差 = 偏差² + 方差 + 噪声；复杂度低高偏差、高复杂度对方差。→ p6-l5
- **交叉验证（时间切分）**：时序必须按时间块切，随机洗牌 = 泄漏未来。→ p6-l5
- **正则化 / 早停**：损失加权重惩罚压自由度 / 验证误差回升前停止训练。→ p6-l5
- **精确率 / 召回率**：预测涨且真涨 ÷ 预测涨（信号可靠度）/ ÷ 实际涨（抓到多少）。→ p6-l7
- **马尔可夫性质**：状态包含决策所需的全部历史信息（RL 状态设计的前提）。→ p6-l6
