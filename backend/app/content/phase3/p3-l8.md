> **前置知识：** 第三章 p3-l0~p3-l7 全部（策略/回测/指标/成本）。
> **学完能做什么：** 独立完成一份完整回测报告：选标的、实现策略、跑通回测、交付四类指标与成本敏感性。

## 产出目标

本课交付一份**完整的策略回测报告**：选择一个标的、实现一类策略、跑通回测、呈现四类绩效指标。格式可复用第一章 p1-l12 的作业形态，但内容从「个股分析」升级为「策略分析」。

## 报告结构

**1. 策略定义**：信号 → 持仓 → 交易三段式写清楚，参数值与其含义（如 MA20/60 中的 20、60 各代表什么），策略世界观（顺势 / 逆势 / 动量）。

**2. 数据与口径**：标的、回测区间、复权方式、成交时点（次日开盘价）、收益口径（复权连乘、不含首日、ddof=1、几何年化）——直接复用 p3-l5 的约定表。

**3. 交易记录**：列出每次信号切换的日期、方向、持仓变化与成交价。交易记录是回测报告里最容易被忽略却最能暴露问题的部分；一笔一笔核对，能发现前视、漏算成本等问题。

**4. 绩效指标**：p3-l6 的四类指标全表（收益、风险、风险调整、交易），与买入持有基准对比。

**5. 成本敏感性**：至少给出 0 / 5 / 10 / 20 bp 四档单边成本下的净收益（p3-l7 表格格式），并据此说明策略对成本的敏感度。

## 自检清单

交付前逐项检查，任何一项不通过都要回去修：

- [ ] 数据来自 真实行情库，代码可复算；
- [ ] 成交时点是信号次日开盘价（无前视）；
- [ ] 收益口径与全课程一致（不含首日、几何年化）；
- [ ] 报告同时列出毛收益与净收益（含成本假设）；
- [ ] 交易记录可逐笔核对，无凭空买卖；
- [ ] 参数敏感性已检查（最优参数周围 ±20% 依然成立）；
- [ ] 结论部分说明了策略的适用市况与失效条件。

## 体检五维度

交付前还可以用 XQuant 的「5 个关键视角」给策略做一次完整体检——每个视角对应报告里的一块内容：

1. **跟什么比（基准）**：策略打败买入持有没有？基准三层里至少报了策略基准（p3-l6）；
2. **每年都有收益吗（逐年）**：把净值按年拆解，收益是否集中在少数年份（p3-l6 逐年拆解）；
3. **收益结构**：胜率 + 盈亏比都报了没有？低胜率高盈亏比也是好策略（p3-l6 胜率陷阱）；
4. **回撤与恢复**：最大回撤 + 水下期间都报了没有？跌多深、套多久是两回事（p3-l6 水下曲线）；
5. **参数动一动**：最优参数 ±20% 邻居是否依然成立？锯齿越尖锐越可疑（p3-l5 锯齿/高原型）。

**先猜后验、数据说了算**——这五个视角不是装饰，是让「策略是真好还是碰巧好」无处遁形的体检表。报告里五个视角逐一给出证据，才算一份合格的阶段产出。

## 参考实现框架

```python
# 最小回测骨架（数据 → 信号 → 次日成交 → 净值）
import pandas as pd

df = pd.read_csv('moutai.csv', parse_dates=['trade_date'])
df['ret'] = df['pct_chg'] / 100 # 复权收益
df['ma_fast'] = df['close'].rolling(20).mean()
df['ma_slow'] = df['close'].rolling(60).mean()
df['signal'] = (df['ma_fast'] > df['ma_slow']).astype(int)
df['pos'] = df['signal'].shift(1).fillna(0) # 次日生效，杜绝前视
df['strat'] = df['ret'] * df['pos'] # 策略日收益
df['nav'] = (1 + df['strat']).cumprod() # 净值
```

输出报告的最终形式：净值曲线图 + 绩效指标表 + 成本敏感性表，标题注明数据口径。这份报告就是你的「量化能力的第一块里程碑」——从读懂指标，到能独立验证一个交易想法。

## 本章生态：策略与回测生态

第三章自己实现了朴素回测引擎——现实世界中，同样的工作有成熟的工具与平台：

- **开源回测框架**：Backtrader（经典，策略/数据/经纪人抽象清晰，文档全）、vn.py（国产，回测+实盘一体，适合 A 股/期货）、zipline（Quantopian 遗产，学术友好）、vectorbt（向量化回测，跑得快）——本章教你「口径是灵魂」，换到这些框架时，同样要核对它们的成交价/成本/收益口径是否符合本章的约定；
- **云量化平台**：聚宽 JoinQuant、米筐 RiceQuant、掘金 MyQuant、BigQuant——提供「在线写策略 + 历史回测 + 模拟盘」的一站式环境，数据源内置，新手友好；个人量化常用它们跑模拟盘验证想法；
- **券商终端**：QMT（迅投）、Ptrade（恒生）——实盘级策略交易终端，可接券商账户直接下单，适合从模拟盘走向实盘的阶段（p7-l4 详讲）；
- **社区**：聚宽社区（策略分享与教程）、掘金量化社区、Datawhale（开源课程）——第三章参考的 XQuant、WhaleQuant 都是其中的代表。

第三章的定位是「把引擎讲透」，而生态的价值是「用的时候知道去哪找趁手的工具」。
