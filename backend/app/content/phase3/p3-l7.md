## 产出目标

本课交付一份**多因子选股策略报告**：选一个因子组合、打分合成、Top K 选股、跑通回测、输出绩效与归因。报告结构复用第二章 p2-l8 的框架，但核心从「单策略」升级为「多因子横截面选股」。

## 真实参考：QuantLab 多因子回测

QuantLab 已有多因子回测的真实结果（`backtest_result` 表），这是本课报告的**参考基准**——用真实净值曲线理解多因子策略的收益形态：

:::viz factor_backtest_dashboard caption=QuantLab 真实多因子回测（backtest_result 表）：每行是一个因子组合回测（组合方法、TopK、调仓频率），实线为组合净值、虚线为沪深 300 基准。真实数据显示不同参数下表现分化显著——有的年化 39%、有的年化 -20%，参数敏感性极大。

真实回测统计（最近 20 条）：

- 年化收益区间：**-20.1% ~ +38.6%**；
- 最优 Sharpe：**1.01**（top20 日频）；
- 正 Sharpe 回测占比：**15/20**。

关键观察：**参数决定成败**。同样的因子，top10 vs top50、日频 vs 周频，结果可能天差地别——这是参数过拟合的直接证据。

## 报告结构

**1. 因子定义与合成**：列出所选因子（真实库中的名称）、方向（正/负）、合成权重与理由。必须说明为何选这几个因子（相关性低、IC 达标）。

**2. 数据与口径**：标的池（全市场/沪深300）、区间、复权方式、中性化方式（第 4 课）、收益口径（复权连乘、不含首日、几何年化）。

**3. 回测配置**：Top K、N_drop、调仓频率、成交时点（次日开盘）、成本假设。逐项写清，呼应 p2-l5 的「口径是灵魂」。

**4. 绩效指标**：与基准（沪深 300）对比——年化、波动、Sharpe、最大回撤、超额、胜率。

**5. 归因与敏感性**：① 因子归因（第 6 课）：超额来自行业 $\beta$ 还是选股 alpha？② 参数敏感性（本课）：最优参数周围 ±20% 是否依然成立？③ 成本敏感性（第 2 章 p2-l7）：换手成本吃掉多少收益？

## 自检清单

交付前逐项检查：

- [ ] 因子来自 quantlab 真实 factor 表，代码可复算；
- [ ] 合成前做过因子相关性检查，无冗余重复加权；
- [ ] 中性化方法已说明（行业/市值）；
- [ ] 成交时点次日开盘，无前视（p2-l5）；
- [ ] 报告同时给毛收益与净收益（含成本）；
- [ ] 最优参数做 ±20% 敏感性检验；
- [ ] 归因部分回答「超额来自行业还是选股」。

## 参考实现框架

```python
# 最小多因子回测骨架（打分 → TopK → 调仓 → 净值）
import pandas as pd

# factor_vals: MultiIndex(date, code) 的因子值表；fwd_ret: 下期收益
def score(factor_vals, weights):
    ranks = factor_vals.rank(pct=True)          # 每期每因子转 0~1 分
    return (ranks * weights).sum(axis=1)        # 加权综合分

def select_topk(scores, k):
    return scores.groupby(level=0).nlargest(k).reset_index(level=0, drop=True)

# 每期选 TopK，组合等权，持有到下期调仓——回测口径与 p2-l5 一致
```

**练习 2（选择题）：** 自检清单中「最优参数做 ±20% 敏感性检验」的目的。

:::quiz
Q: 报告自检清单要求「最优参数做 ±20% 敏感性检验」，其目的是？
- 检验参数过拟合：最优参数周围 ±20% 是否依然成立
- 让收益变得更高
- 去掉基准比较
- 增加因子数量

E: 最优参数附近大幅劣化说明参数过拟合（呼应本课参数敏感性）；敏感性检验是报告可信度的关键一环。

**练习 4（选择题）：** 「最优 Sharpe」是被挑选出来的极大值，不能代表典型表现。

:::quiz
Q: QuantLab 真实回测统计「最近 20 条中正 Sharpe 15 条、最优 Sharpe 1.01」。报告中直接引用「最优 Sharpe 1.01」作为策略表现，主要风险是？
- 没有风险，挑选最优值是行业标准做法
- 最优值是被挑选出来的极大值、天然偏高，不能代表策略典型表现——应报告分布（15/20）与区间（-13.1% ~ +38.6%）
- Sharpe 不可能超过 1
- 应该把 20 条回测的 Sharpe 全部平均后使用
A: 2
E: 多重比较下「最优值」存在选择偏差：20 条里挑最大，期望值天然偏高；诚实报告应给出分布、区间与「最优参数是样本内选择」的标注，并做 $\pm 20\%$ 敏感性检验。
:::

## 本章生态：因子研究与投研平台生态

第三章的因子分析在行业里有成体系的工具链：

- **因子研究框架**：Microsoft Qlib（开源，数据→因子→模型→回测→组合全链路，A 股友好）、WorldQuant BRAIN（在线挖因子平台，有青训营和实盘激励）、Alphalens（因子分析可视化，对齐 IC/分层收益本课的框架）；
- **数据源**：Baostock（免费）、Tushare Pro（财务/行情）、聚宽 JQData / 米筐 rqdatac（因子研究常用，覆盖 PIT 财务与行业分类）；
- **行业分类体系**：申万行业分类（本课主线所用）、中信分类、中证分类——中性化（p3-l4）依赖的分类标准不同，结论会不同；
- **社区与赛事**：WorldQuant 挑战赛、中金/华泰等券商的金工研报（单因子检验、多因子模型的标准范式）、QuantChina 社区、聚宽社区的因子研究帖——第三章的「三板斧」正是这些机构研报的通用框架。

行业里没有「开箱即用」的因子库——每个团队都基于自己的数据与口径重做一遍检验，这正是本章值得认真学的原因。
