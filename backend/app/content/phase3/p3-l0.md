## 为什么需要量化

先看一个人做交易的常见样子：看新闻、凭感觉、听消息，追涨杀跌，赚了拿不住、亏了死扛。问题不在「判断错了」，而在**决策过程不可重复**——同样的行情今天一个决定、明天另一个决定，事后无法复盘。

人脑做交易有几个天然短板：

1. **情绪干扰**：恐慌时割肉、贪婪时加仓，和规则无关；
2. **不一致**：同一个信号，今天执行、明天不执行；
3. **不可回溯**：判断的依据说不清，亏了不知错在哪。

量化要解决的，正是这三个问题——**把决策变成明确的规则，让计算机严格、一致地执行，并且每一次决定都可回溯、可检验**。

## 何为量化

**量化（quantitative investing）是用规则和数据代替「感觉」来做投资决策**。一条规则要能被计算机执行，必须满足三个条件：

1. **信号明确**：什么条件触发？（如「MA20 上穿 MA60」）不能有「差不多」「感觉要涨」这类模糊表述；
2. **持仓可映射**：触发后怎么操作？（买入/卖出/持仓多少）——这就是第一章 p3-l1 讲的**信号 → 持仓 → 交易**三段；
3. **参数可复算**：用了哪些参数（均线周期、阈值）？别人拿着同样的数据能算出同样的结果。

一个能跑起来的策略，本质就是「**把交易想法装进固定框架**」——先定义做什么（初始化），再定义每个交易日做什么（周期循环）。这个框架让人脑的「灵感」变成机器可执行、历史可验证的程序。**先猜后验、数据说了算**，是整章的方法论底色。

## 量化的价值

把决策规则化之后，三个好处自然出现：

1. **可验证**：规则写好后，可以在历史数据上「重放」——这就是回测。10 年的规则，几秒跑完，「如果从过去跑到现在会怎样」有了答案；
2. **可迭代**：发现规则有缺陷，改一处重新跑，前后的差异一目了然；主观交易做不到这种「可复现的改进」；
3. **可规模化**：规则写好，盯一只股票和盯一百只股票是同一套代码；人做不到每天分析一百只，机器可以。

但也要先泼盆冷水：量化不是印钞机。回测漂亮 ≠ 未来赚钱——历史里没有的情况、参数过拟合、成本侵蚀，都可能让「看起来很好」的策略在实盘失效（本章回测课专门讲这些坑）。**量化提高的是决策质量，不是保证收益**。

## 需要准备什么

学习本章只需要三样东西，且前面的章节都已备好：

1. **真实数据**：真实 A 股日线（第一章已会用 `get_daily` 读取）；
2. **编程工具**：Python + 代码沙箱（第一章已跑通，本章策略直接在沙箱里实现和回测）；
3. **统计基础**：均值、方差、标准差、收益与风险的口径（Phase 0 / 第一章已讲）。

不需要额外的软件、账号或平台——本课程的所有策略、回测、指标都在沙箱里基于真实数据完成。

## 本章地图

第三章的路径是一个完整的策略闭环：

1. **策略三要素**（p3-l1）：信号 → 持仓 → 交易；
2. **三大策略家族**（p3-l2/3/4）：趋势跟踪、均值回归、动量——它们分别赌市场「延续」「回归」「惯性」；
3. **回测**（p3-l5）：怎么在历史上重放策略、口径怎么统一、有哪些坑（前视/幸存者/过拟合）；
4. **绩效评估**（p3-l6）：四类指标怎么算、怎么把策略摆上同一张表去读、去比；
5. **交易成本**（p3-l7）：毛收益与净收益之间的裂缝；
6. **阶段产出**（p3-l8）：独立完成一份完整回测报告。

学完这一章，你能回答：什么是量化、怎么写一个策略、怎么回测、怎么看回测结果靠不靠得住——以及最重要的，**为什么「数据说了算」**。

## 动手实验：用真实数据数一数「规则有多少个信号」

「金叉就买」说了半天，它在真实数据里到底给出多少个信号？下面的沙箱在茅台 2020-2026 日线上数 MA20/60 的金叉与死叉次数——这就是 p3-l1 三段式的信号段在真实数据上的样子：

:::viz code_sandbox caption=数信号（真实茅台 2020-2026）：MA20/60 均线关系逐日判定看多/看空，统计金叉、死叉与信号切换次数。这些数字就是第三章所有对比表的「原料」——规则一旦确定，信号数量就是确定的、可复算的。
import pandas as pd

df = get_daily('sh600519', '2020-01-02', '2026-08-10')
fast = df['close'].rolling(20).mean()
slow = df['close'].rolling(60).mean()
sig = (fast > slow).astype(int)          # 1 看多，0 看空——规则完全确定

golden = int((sig.diff() == 1).sum())    # 0→1：金叉
dead = int((sig.diff() == -1).sum())     # 1→0：死叉
print(f"金叉 {golden} 次，死叉 {dead} 次，信号切换共 {golden + dead} 次")
print(f"看多天数占比 {sig.mean()*100:.1f}%")

# === 预期输出 ===
金叉约 17 次，死叉约 16 次，信号切换共约 33 次（±2 次以内；与 p3-l6 对比表「均线交易次数 17」一致，微小出入来自沙箱用复权价计算信号）
看多天数占比约 46%（与 p3-l2 主线表「持仓占比 46.3%」一致）
:::

对照预期输出自检后，注意两个数字的含义：**金叉 17 次**意味着 6 年半里规则只给了 17 次进场机会——「规则化」不是高频交易，双均线在日频上是低频策略；**看多占比约 46%** 意味着一半以上的时间空仓——这正是 p3-l2「趋势策略的价值在躲不在追」的数据基础。信号数量完全由参数和数据决定，没有感觉的参与空间——这就是 p3-l1 说的「可复现」。

## 练习题

**练习 1（选择题）：** 量化的本质。

:::quiz
Q: 量化投资最本质的特征是?
- 使用昂贵的软件和服务器
- 用明确规则和数据代替「感觉」做决策，决策可重复、可回溯
- 一定能获得比主观交易更高的收益
- 只适用于机构，个人无法参与
A: 2
E: 量化的核心是把决策规则化——信号明确、持仓可映射、参数可复算，从而可回测、可迭代、可规模化。
:::

**练习 2（选择题）：** 规则可被计算机执行的条件。

:::quiz
Q: 一条交易规则要能被计算机执行，下列哪项不是必要条件?
- 信号明确，无「差不多」「感觉要涨」等模糊表述
- 触发后操作明确（买入/卖出/持仓多少）
- 参数可复算，别人用同样数据能算出同样结果
- 规则在过去十年都赚钱
A: 4
E: 可执行的三要素是信号明确、持仓可映射、参数可复算；「过去十年都赚钱」是回测要检验的事，不是可执行的前提。
:::

**练习 3（选择题）：** 量化的价值。

:::quiz
Q: 「规则化 → 可回测 → 可迭代」这一链条的核心好处是?
- 回测保证未来盈利
- 规则不好可以改一处重新跑，前后差异一目了然，实现「可复现的改进」
- 量化消除了所有交易风险
- 规则越多越好
A: 2
E: 可验证、可迭代、可规模化是规则化的三大好处；但回测不等于未来收益，量化提高的是决策质量而非收益保证。
:::

**练习 4（应用题）：** 把一句「感觉」改写成可执行的规则。

:::exercise
T: 有人告诉你他的交易方法是：「我觉得茅台要涨的时候就买，感觉差不多了就卖。」请指出这句话在「信号明确 / 持仓可映射 / 参数可复算」三个维度上分别缺了什么，并把它改写成一条可被计算机执行的规则（给出信号、操作与参数）。

（追问）改写后，这条规则在 2020-2026 的茅台数据上应该用什么工具来检验「它到底行不行」？检验结果要回答什么问题？这和「感觉对了」的判断有什么本质区别？

:::

:::answer
- **三要素缺失**：「我觉得要涨」没有信号定义（什么条件触发？）；「差不多就卖」没有持仓与离场规则（买多少、何时卖）；整句话没有任何参数（均线周期？阈值？）——三条全缺。
- **改写示例**：信号 = MA20 上穿 MA60 看多、下穿看空；持仓 = 看多全仓 1.0、看空 0.0；交易 = 信号次日开盘价成交；参数 = (20, 60)。
- **检验工具**：回测引擎（p3-l5 的朴素引擎或本课程模拟器），在同一窗口、同一口径（复权、次日成交）下输出净值与四类指标（p3-l6）。
- **要回答的问题**：累计/年化收益多少？最大回撤多少？夏普多少？扣成本后还剩多少？换参数还稳吗？
- **本质区别**：「感觉对了」无法复现、无法归因、也无法证伪；回测把判断变成「可复算的数字 + 已知口径」——错了能定位错在哪一环，这是量化与主观交易的分水岭。
:::
