> **前置知识：** 全书：数据→因子→策略→组合→风控→实盘七章全部。
> **学完能做什么：** 独立设计一条完整量化 pipeline，逐环写出做法与检查项，理解「回测能赚 ≠ 实盘能赚」。

## 完整 pipeline

量化投资是一条链，任何一环断裂，整体失效：

```
数据获取 → 因子/特征 → 策略/模型 → 组合配置 → 风险控制 → 执行/实盘
（第1章） （第4/6章） （第3/6章） （第7章）  （第7章）  （第7章）
```

- **数据**：真实行情（第一章贯穿主线茅台，真实行情库）；
- **因子**：单因子检验与多因子合成（第四章，161 个真实因子）；
- **策略**：传统规则（第三章）与 ML 模型（第六章，逻辑回归/梯度下降）；
- **组合**：马科维茨有效前沿、风险平价、Black-Litterman 观点融合（第七章）；
- **风控**：止损、压力测试、仓位管理（第七章）；
- **执行**：模拟盘验证 → 实盘上线（第七章）。

这条链不是六个独立模块的简单串联，而是**层层放大的误差链**：前一环的误差会顺着链条被后续环节放大。数据口径错了（未复权），因子计算全错；因子选错了（过拟合），模型学到的信号是噪音；模型预测不准，组合配置的最优化就成了「对错误预期的精确求解」；组合再准，没有风控，一次极端行情就让全部积累清零。**每一环都在为上一环的误差买单**——这就是为什么全书反复强调「先验证再前进」。

把这条链画成架构图，每一环都能点开看它的输入、检查项与出错后果：

先看**六个环节的先后顺序**：数据在最前、实盘在最后，箭头只朝一个方向——前一环的输出是后一环的输入，**没有回头路**。再**逐个点击环节**：每一环都对应书里的具体章节与真实数据（如「因子」对应第四章的 161 个真实因子、「组合」对应第七章的 5 股真实收益矩阵）——这不是抽象架构，而是全书知识在一条链上的投影。最后**打开「错误传导方向」**：六环全部标红，提示每一环出错都会连累下游——这正是正文「层层放大的误差链」的图形化。

## 组合层的作用

第七章的三种组合方法解决不同问题：

- **马科维茨**：给定收益预测，找到最优分散化（依赖 $\mu$ 估计）；
- **风险平价**：不预测收益，只均衡风险（稳健，适合无观点时）；
- **Black-Litterman**：在均衡基础上融入观点（把预测与纪律结合）。

第六章的 ML 预测正可作为组合的**收益输入**：预测准 → 马科维茨/BL 有意义；预测不准 → 风险平价兜底。组合与预测共同决定最终配置。

## 风险控制是最后防线

第七章可视化已展示：止损限住最坏情况、压力测试揭示极端损失、仓位控制防止过度集中。**回测收益是「理论值」，风控决定「实际值」**——这是从模拟到实盘的分水岭。

为什么风控是「最后防线」而不是「锦上添花」？因为前面五环都在「争取收益」，只有风控在「保证生存」：收益是积累出来的，而一次未受控的回撤就能抹掉多年积累（p3-l6 的「回本需 1/(1-MDD)−1」）。实盘与回测的最大差异不在于「预测准不准」，而在于**回测里你永远不会爆仓，实盘里会**——回测输光了还能重跑，实盘输光了就出局。风控就是给这个「出局风险」设的保险丝。

## 全流程核查清单

- [ ] 数据真实、口径统一（复权、不含首日）
- [ ] 回测无前视偏差、成本已计入
- [ ] ML 模型过了交叉验证与时间切分
- [ ] 组合配置有明确依据（前沿/平价/BL）
- [ ] 止损、仓位、压力测试全部代码化
- [ ] 模拟盘稳定运行后才考虑实盘

## 结语

从「货币时间价值」到「实盘 pipeline」，七章走完了量化从 0 到 1 的完整路径。前几章的关键数字贯穿始终——茅台的复权收益、夏普、回撤；第六章学会了「模型有用 ≠ 策略赚钱」；第七章学会「回测能赚 ≠ 实盘能赚」。量化是一段持续学习的过程：**数据在变、市场在变，但纪律不变**——真实的检验，永远在样本之外。

## 练习题

**练习 1（选择题）：** 回测收益与实际收益的关系。

:::quiz
Q: 关于「回测收益 vs 实际收益」，正确的认识是？
- 回测收益就是实盘收益
- 回测收益是理论值，风控决定实际值
- 实际收益只取决于预测精度
- 风控只影响回撤、不影响收益
A: 2
E: 回测假设理想成交（收盘价/次日价、无冲击），实盘收益被执行成本与风控重新书写——「回测能赚 ≠ 实盘能赚」。

- Black-Litterman
- 风险平价
- 集中持仓
A: 3

追一问：若你手上只有茅台约 21 个交易日的日线数据（约 1 个月），请指出上述 pipeline 中哪个环节会最先出问题、为什么（结合样本量对因子检验、ML 训练与回测的意义），并给出最小可行的改进方案。


:::answer
- **主答**：数据——复权日线、无假跳空检查；因子——MA20/60、20 日波动，shift 对齐无前视；策略——金叉满仓/死叉空仓、次日开盘成交；组合——单标的全仓（组合层退化）；风控——-15% 回撤止损 + 日内限单 1 次，全部代码化；执行——模拟盘 1 个月再小资金。ML 接入：预测上涨概率超阈值才允许开仓（风控前置过滤）；预测不准退回纯规则兜底（p7-l6 组合层）。
- **追问**：最先崩的是**因子检验与模型训练**：21 天样本上 IC 无显著性（$t=ICIR\sqrt T$）、ML 必然过拟合到噪声。最小改进：窗口拉到 ≥3 年，或把 21 天定义为「模拟盘调试期」而非研究样本——样本量约束（p3-l5 标准误）在这里是硬性的。
:::

追一问：这四类问题中，哪两类是「回测收益被高估」的直接来源、哪两类是「实盘灾难」的隐患？请分别对应第三章（前视偏差/交易成本）与第七章（风控代码化/模拟盘时长）的具体概念加以说明。


:::answer
- **主答**：① 未复权价 → 除权假跳空污染全部数字（p1-l2）→ 统一复权重算；② 当日收盘成交 → 前视（p3-l5）→ 次日开盘成交；③ 止损只在文档 → 人工执行不可靠（p7-l3）→ 代码化+告警；④ 模拟盘 3 天 → 未覆盖涨跌停/停牌/断流等工程失效（p7-l4 要求 ≥1 个月）→ 至少 1 个月 + 小资金试运行。
- **追问**：回测虚高的直接来源是 **①+②**（口径错+前视，发生在回测数字里）；实盘灾难隐患是 **③+④**（风控不落地+工程未验证）——前者对应第三章「口径是灵魂」，后者对应第七章「风控决定实际值」。共同底色：**结论可信度由最弱一环决定**（误差传导链）。

:::quiz
Q: 用未复权（不复权）价格序列计算某只分红股票的 2024 年收益，最可能的影响是？
- 没有任何影响
- 除权日出现虚假「下跌」，计算出的收益被低估

- 只影响波动率、不影响收益

## 本章生态：实盘链路生态

第七章把「从 0 到实盘」串成完整链路——真实世界里，这条链路的每一环都有对应的工具生态：

- **研究与回测**：聚宽/米筐/掘金（在线回测+模拟盘）、Backtrader/vn.py（本地回测）、vectorbt（向量化快速验证）——本书的「统一擂台」思想在这些平台上对应「统一基准、统一口径」的设定；
- **模拟交易**：聚宽模拟盘、掘金模拟盘、券商仿真环境——模拟盘与实盘的核心差异（成交价、流动性、心理压力）在第七章已讲透；
- **实盘交易接口**：QMT（迅投，券商量化终端）、Ptrade（恒生）、vn.py 对接的券商柜台接口、东方财富/华泰等券商自研 API——个人实盘的主流路径是「券商开通 QMT/Ptrade + 自己写策略对接」；
- **风控与监控**：自研风控模块（第七章代码化的止损/仓位/压力测试）、券商端的强平/风控规则、监控告警工具（如 Grafana + 消息推送）——「风控决定实际值」在实盘中由这些系统强制执行；
- **社区**：掘金社区、聚宽社区、vn.py 社区、知乎量化专栏——实盘踩坑经验（滑点、断线、涨跌停不可成交）在这些社区里都有真实讨论。

第七章的结论——「回测能赚 ≠ 实盘能赚」——是整个生态里最常被验证也最常被忽视的一句话。真正的检验，永远在样本之外。
