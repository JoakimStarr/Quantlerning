> **前置知识：** 第四章 p4-l1~p4-l6 全部（因子/检验/合成/归因）。
> **学完能做什么：** 独立完成多因子策略报告：选因子→打分→回测→归因，交付年化超额与风险拆解，并用「诚实形式」呈现结果。

## 产出目标

本课交付一份**多因子选股策略报告**：选一个因子组合、打分合成、Top K 选股、跑通回测、输出绩效与归因。报告结构复用第三章 p3-l8 的框架，但核心从「单策略」升级为「多因子横截面选股」。

## 真实参考：多因子回测

先看一份现成的多因子回测结果，理解真实收益形态是什么样的。这里把每个因子组合回测的净值与基准放在一起：

:::viz factor_backtest_dashboard caption=真实多因子回测（多因子组合回测结果）：每行是一个因子组合回测（组合方法、TopK、调仓频率），实线为组合净值、虚线为沪深 300 基准。不同参数下表现分化显著——有的年化 38.6%、有的年化 -20.1%，参数敏感性极大。
:::

真实回测统计（最近 20 条）：

- 年化收益区间：**-20.1% ~ +38.6%**；
- 最优 Sharpe：**1.01**（top20 日频）；
- 正 Sharpe 回测占比：**15/20**。

关键观察：**参数决定成败**。同样的因子，top10 vs top50、日频 vs 周频，结果可能天差地别——这是参数过拟合的直接证据。所以这份报告的每一节，都要回答「我为什么这么选」。

## 报告结构

**1. 因子定义与合成**：列出所选因子（真实库中的名称）、方向（正/负）、合成权重与理由。必须说明为何选这几个因子（相关性低、IC 达标、换手可接受）。权重怎么定，要说清楚：等权、ICIR 加权、还是带相关性惩罚，每种选择的理由和代价都写一行，读者才能判断这是「选出来的」还是「试出来的」。

**2. 数据与口径**：标的池（全市场/沪深300）、区间、复权方式、中性化方式（第 4 课）、收益口径（复权连乘、不含首日、几何年化）。这一节最枯燥，也最不能省——口径错一个，后面所有结论都悬空。第三章说「口径是灵魂」，在这里就是：报告开头把口径钉死，后续每个数字都有据可查。

**3. 回测配置**：Top K、N_drop、调仓频率、成交时点（次日开盘）、成本假设。逐项写清，呼应 p3-l5 的「口径是灵魂」。每个参数给一句「为什么」：TopK 为什么取 20 而不是 50？调仓为什么月度不是周度？成本假设单边多少、基于什么？这些问题不回答，回测就成了「调参游戏」。

**4. 绩效指标**：与基准（沪深 300）对比——年化、波动、Sharpe、最大回撤、超额、胜率。一张对比表 + 一张净值曲线就够。关键是把「超额」拆开：毛超额多少、剔行业/风格后还剩多少（第 6 课归因），两个口径都报。

**5. 归因与敏感性**：① 因子归因（第 6 课）：超额来自行业 $\beta$ 还是选股 alpha？② 参数敏感性（本课）：最优参数周围 ±20% 是否依然成立？③ 成本敏感性（第 2 章 p3-l7）：换手成本吃掉多少收益？

## 结果呈现的诚实形式

回测最容易踩的坑，是只报「最优那条」。真实回测里 20 条结果年化从 -20.1% 到 +38.6% 都有，最优 Sharpe 1.01 只是 top20 日频这一条。只报它，报告就失真了。诚实的呈现分三层：

**① 完整结果网格**。把试过的参数全部列出来（组合方法、TopK、调仓频率、年化/Sharpe/回撤），不筛选、不删差结果。读者能自己看到「最优参数旁边是什么样」。

**② 分布而不是点值**。报告年化收益的区间、Sharpe 的正负占比（如 15/20），而不是单点。分布让「最好结果」回到它本来的位置：它是 20 个点里的极值，不是典型值。

**③ 敏感性标注**。明确标出「最优参数是样本内选择」，并给出最优参数 ±20% 邻域的表现。邻域内表现断崖式下跌，就是过拟合的直接证据（呼应 p3-l5 的锯齿现象）。

这三层合起来，就是「口径是灵魂」在报告环节的落地——回测报告的价值，一半在结果，一半在「结果是怎么被挑选和呈现的」。

## 自检清单

交付前逐项检查：

- [ ] 因子来自真实因子库，代码可复算；
- [ ] 合成前做过因子相关性检查，无冗余重复加权；
- [ ] 中性化方法已说明（行业/市值）；
- [ ] 成交时点次日开盘，无前视（p3-l5）；
- [ ] 报告同时给毛收益与净收益（含成本）；
- [ ] 最优参数做 ±20% 敏感性检验；
- [ ] 归因部分回答「超额来自行业还是选股」；
- [ ] 结果用完整网格 + 分布呈现，不只报最优。

## 参考实现框架

```python
# 最小多因子回测骨架（打分 → TopK → 调仓 → 净值）
import pandas as pd

# factor_vals: MultiIndex(date, code) 的因子值表；fwd_ret: 下期收益
def score(factor_vals, weights):
    ranks = factor_vals.rank(pct=True)          # 每期每因子转 0~1 分
    return (ranks * weights).sum(axis=1)        # 加权综合分

def select_topk(scores, k):
    return scores.groupby(level=0).nlargest(k).reset_index(level=0, drop=True)

# 每期选 TopK，组合等权，持有到下期调仓——回测口径与 p3-l5 一致
```

**练习 1（选择题）：** 真实多因子回测的表现区间。

:::quiz
Q: 真实多因子回测（最近 20 条）的年化收益区间与最优 Sharpe 约为？
- 年化 -20.1% ~ +38.6%，最优 Sharpe 1.01（top20 日频）
- 年化 -20.1% ~ +38.6%，最优 Sharpe 0.1
- 年化 5% ~ 10%，所有回测 Sharpe 相同
- 年化 38.6%，无亏损回测
A: 1
E: 年化区间 -20.1% ~ +38.6%、最优 Sharpe 1.01、正 Sharpe 占比 15/20——同样的因子不同参数结果天差地别，参数决定成败。
:::

**练习 2（选择题）：** 自检清单中「最优参数做 ±20% 敏感性检验」的目的。

:::quiz
Q: 报告自检清单要求「最优参数做 ±20% 敏感性检验」，其目的是？
- 检验参数过拟合：最优参数周围 ±20% 是否依然成立
- 让收益变得更高
- 去掉基准比较
- 增加因子数量
A: 1
E: 最优参数附近大幅劣化说明参数过拟合（呼应本课参数敏感性）；敏感性检验是报告可信度的关键一环。
:::

**练习 4（选择题）：** 「最优 Sharpe」是被挑选出来的极大值，不能代表典型表现。

:::quiz
Q: 真实回测统计「最近 20 条中正 Sharpe 15 条、最优 Sharpe 1.01」。报告中直接引用「最优 Sharpe 1.01」作为策略表现，主要风险是？
- 没有风险，挑选最优值是行业标准做法
- 最优值是被挑选出来的极大值、天然偏高，不能代表策略典型表现——应报告分布（15/20）与区间（-20.1% ~ +38.6%）
- Sharpe 不可能超过 1
- 应该把 20 条回测的 Sharpe 全部平均后使用
A: 2
E: 多重比较下「最优值」存在选择偏差：20 条里挑最大，期望值天然偏高；诚实报告应给出分布、区间与「最优参数是样本内选择」的标注，并做 $\pm 20\%$ 敏感性检验。
:::

**练习 5（选择题）：** 完整结果网格的意义。

:::quiz
Q: 报告要求给出「完整结果网格」（组合方法、TopK、调仓频率、绩效），主要意义是？
- 凑篇幅，让报告看起来更厚
- 让读者能看到最优参数周边的表现，避免「最优值选择偏差」，结果可复核
- 网格里差的结果可以删掉
- 网格与敏感性无关
A: 2
E: 完整网格不筛选、不删差结果，读者能自己判断最优参数是不是孤例；配合 ±20% 敏感性标注，才构成诚实的报告。
:::

## 本章生态：因子研究与投研平台生态

第四章的因子分析在行业里有成体系的工具链：

- **因子研究框架**：Microsoft Qlib（开源，数据→因子→模型→回测→组合全链路，A 股友好）、WorldQuant BRAIN（在线挖因子平台，有青训营和实盘激励）、Alphalens（因子分析可视化，对齐 IC/分层收益本课的框架）；
- **数据源**：Baostock（免费）、Tushare Pro（财务/行情）、聚宽 JQData / 米筐 rqdatac（因子研究常用，覆盖 PIT 财务与行业分类）；
- **行业分类体系**：申万行业分类（本课主线所用）、中信分类、中证分类——中性化（p4-l4）依赖的分类标准不同，结论会不同；
- **社区与赛事**：WorldQuant 挑战赛、中金/华泰等券商的金工研报（单因子检验、多因子模型的标准范式）、QuantChina 社区、聚宽社区的因子研究帖——第四章的「三板斧」正是这些机构研报的通用框架。

行业里没有「开箱即用」的因子库——每个团队都基于自己的数据与口径重做一遍检验，这正是本章值得认真学的原因。
