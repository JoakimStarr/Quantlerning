## 数据源概览

- **Baostock**：免费、无 token，日线/财务/指数，适合本地量化；
- **Tushare**：数据丰富，积分制；
- **AKShare**：接口最多，稳定性稍差。

QuantLab 底层用 baostock，已同步 10 年 A 股日线到本地 PostgreSQL——本课程主线数据（茅台 2024）即来自这里。

## Baostock 拉取真实数据

```python
import baostock as bs
import pandas as pd

bs.login()
rs = bs.query_history_k_data_plus(
    'sh.600519',
    'date,code,open,high,low,close,volume,amount,pctChg',
    start_date='2024-01-01', end_date='2024-12-31',
    frequency='d', adjustflag='2')

rows = []
while rs.error_code == '0' and rs.next()：
    rows.append(rs.get_row_data())
df = pd.DataFrame(rows, columns=rs.fields)
bs.logout()
```

`adjustflag=2` 表示**前复权**——处理分红送股，让历史价格可比。

## 复权为什么重要

不复权数据在除权日有「假跳空」，导致收益计算错误：
- 除权日价格「凭空下跌」→ 错误的跌幅；
- 历史收益被低估。

**前复权**：以最新价为基准回算历史，当前价不变：**后复权**：以最早价为基准，价格永不回落。量化计算一律用复权价——主线数据的收益都基于复权口径。下方演示可直观看到复权与不复权在除权日的分叉：

:::viz real_vs_log caption=复权与未复权（真实茅台 2024）：三条累计净值曲线——复权累计（主线口径，蓝）、未复权累计（红）、对数收益累计（橙）。6 月分红除权日，复权曲线平滑通过，未复权曲线出现「假跳空」——同一笔分红，两种口径的收益从此分叉。量化计算一律用复权价。
:::

## 数据质量

```python
df.info()                # 缺失值/类型
df['close'].isnull().sum()  # 停牌日缺失
```

常见问题：停牌日缺失（前向填充）、一字板无量、财报滞后（PIT）。

**真实性原则**：宁可显示「数据缺失」，也不插值掩盖——quantlab 数据是真实行情，缺失即真实缺失。

## 清洗与检查

```python
df['trade_date'] = pd.to_datetime(df['trade_date'])
df = df.sort_values('trade_date').reset_index(drop=True)
df = df.dropna(subset=['close'])   # 去停牌日
df = df[df['close'] > 0]           # 剔异常价
df = df.drop_duplicates(subset=['trade_date'])
```

顺序重要：先排序再算收益，否则 `pct_change` 错位。停牌日缺失是**真实缺失**，不要插值掩盖。

## 收益与指标

```python
df['ret'] = df['close'].pct_change()
df['ma20'] = df['close'].rolling(20).mean()
df['vol20'] = df['ret'].rolling(20).std() * np.sqrt(252)
df['hh20'] = df['high'].rolling(20).max()  # 唐奇安上轨
df['ll20'] = df['low'].rolling(20).min()   # 唐奇安下轨
```

用复权价算收益（`pct_chg` 复权连乘），年化乘 $\sqrt{252}$。特征工程（去极值/标准化/滞后特征）见 p0-l6。

**练习 1（选择题）：** baostock 查询历史行情时，参数 `adjustflag='2'` 表示什么？

:::quiz

A: 2

**练习 2（选择题）：** 用 pandas 计算日收益 $df['close'].pct\_change()$ 之前，必须先做什么？

:::quiz
Q: 用 pandas 计算日收益 $df['close'].pct\_change()$ 之前，必须先？
- 按 trade_date 排序，否则 pct_change 错位
- 删除所有成交量列
- 把日期转成字符串

A: 1
E: pct_change 依赖相邻行顺序，未排序时收益与真实交易顺序不符；先排序再算收益是关键步骤。

**练习 3（选择题）：** $df['vol20']=df['ret'].rolling(20).std()\cdot\sqrt{252}$ 中乘 $\sqrt{252}$ 是因为什么？

:::quiz
Q: $df['vol20']=df['ret'].rolling(20).std()\cdot\sqrt{252}$ 中乘 $\sqrt{252}$ 是因为？
- 把日波动年化（一年约 252 个交易日）
- 消除停牌影响
- 调整复权因子
- 转换为对数收益
A: 1
E: 日波动乘 $\sqrt{252}$ 得到年化波动，便于跨周期比较；这是金融中常用的时间缩放。
:::

**练习 6（选择题）：** 除权日数据处理的易错点。

:::quiz
Q: 某股票 6 月 30 日分红除权，未复权收盘价从 100 元「跌」到 95 元（实际是除权而非下跌）。用未复权价算这天的收益会?
- 得到正确的 0% 收益
- 得到虚假的 -5% 收益，历史收益被低估
- 得到 +5% 收益
- 只影响成交量不影响收益
A: 2
E: 除权日价格「凭空下跌」，未复权价把分红误当跌幅；复权口径剔除分红后才反映真实持有收益，这也是量化统一用复权价的原因。
:::
