## 系统风险与 β

上一课估值反复出现「要求回报率」，但一只股票到底该要求多少回报？凭感觉定太随意。资本资产定价模型（CAPM）给出答案：风险越大的资产，市场要求的回报越高。

资本资产定价模型（CAPM）给出资产期望收益与市场风险之间的关系：

$$E[R_i]=r_f+\beta_i\times(E[R_m]-r_f)$$

其核心思想：**只有无法分散的系统风险才获得补偿**。非系统风险（个股特有风险）可通过分散化消除，市场不会为此付费。

$\beta$ 衡量资产对市场整体的敏感度：

$$\beta=\frac{\operatorname{Cov}(R_i,R_m)}{\operatorname{Var}(R_m)}$$

- $\beta=1$：与市场同涨跌；
- $\beta>1$：放大波动（进攻型）；
- $\beta<1$：防御型；
- $\beta=0$：与市场无关。

:::viz capm_sml beta=1 rf=2 rm=10 caption=SML 证券市场线：$E[R]=r_f+\beta\times(R_m-r_f)$。拖动 $\beta$ 看资产在 SML 上的位置；无风险利率 $r_f$ 决定截距，市场风险溢价 $R_m-r_f$ 决定斜率。
:::

先看**资产点在 SML 上的位置随 $\beta$ 移动**：$\beta=1$ 时资产恰在市场组合处，$\beta>1$ 资产要求更高回报（右上）、$\beta<1$ 要求更低（左下）——「风险越大、要求回报越高」在直线上是一目了然的斜向关系。再**拖动 $r_f$ 与市场风险溢价**：$r_f$ 改变截距（整条线上下平移）、溢价改变斜率（线变陡或变缓）——CAPM 的两个参数各控制一条轴。SML 上方的资产被低估（实际回报高于要求），下方被高估。

## 证券市场线 SML

CAPM 的公式画成图，就是一条直线——**证券市场线（SML）**。

SML 画的是 $\beta$ 与期望收益的直线关系。**所有资产都应落在 SML 上**——这是市场均衡的定价结果：

- 在线上方 → 被低估（实际收益高于 $\beta$ 对应的要求收益，可买）；
- 在线下方 → 被高估（回避/做空）。

CAPM 的实践用途：
- 计算权益资本成本（WACC 的一部分）；
- 评估基金经理是否跑赢「按风险调整后」的基准；
- 定义 $\alpha$（超额收益）——实际收益与 CAPM 要求收益之差，是 Phase 3 因子 $\alpha$ 的起源。

## 真实 $\beta$ 估计

公式里的 $\beta$ 是理论值，实务中怎么得到它？——用**回归**估计。

$\beta$ 在实务中用**回归**估计：把个股日收益 $R_i$ 对市场日收益 $R_m$ 做一元线性回归 $R_i=\alpha+\beta R_m+\varepsilon$，回归斜率即 $\beta$。

:::viz beta_regression caption=真实 $\beta$ 回归（茅台 2020-2026 对上证指数日收益）：每个点是一个交易日的（市场收益，个股收益），红线是 OLS 回归线。拖动/缩放查看散点分布——斜率即 $\beta$，点的聚拢程度决定 R^2。
:::

在沙箱里就能复现这个 $\beta$ 与 α——点「运行」看真实结果与散点图，再动手改：换一只股票、改时间区间、加无风险利率算超额收益：

:::viz code_sandbox caption=代码沙箱：茅台（sh600519）对上证指数（SH_INDEX）2020-2026 日收益的 OLS 回归。`get_daily` 读个股日线，`get_index` 读指数日收盘，按日期对齐后回归——斜率即 $\beta$、截距即 α（日）；最后用 `plt` 画散点图，红线即回归线。点「预期输出」可对照真实数值自检。
import matplotlib.pyplot as plt

mt = get_daily('sh600519', '2020-01-02', '2026-08-10')
sh = get_index('SH_INDEX', '2020-01-02', '2026-08-10')
df = mt[['date', 'pct_chg']].merge(
    sh[['date', 'pct_chg']], on='date', suffixes=('_stock', '_mkt'))
df = df.dropna()

beta = df['pct_chg_stock'].cov(df['pct_chg_mkt']) / df['pct_chg_mkt'].var()
alpha = df['pct_chg_stock'].mean() - beta * df['pct_chg_mkt'].mean()
r2 = df['pct_chg_stock'].corr(df['pct_chg_mkt']) ** 2

print(f'样本 {len(df)} 个交易日')
print(f'$\beta$  = {beta:.3f}')
print(f'α（日） = {alpha:.4f}% → 年化 {alpha * 252:.2f}%')
print(f'R^2 = {r2:.3f}')

# 散点图：市场收益 vs 个股收益，红线斜率即 β
plt.scatter(df['pct_chg_mkt'], df['pct_chg_stock'], s=4, alpha=0.4)
xs = df['pct_chg_mkt'].sort_values()
plt.plot(xs, alpha + beta * xs, color='red', linewidth=2, label=f'$\beta$={beta:.2f}')
plt.xlabel('上证指数日收益 %')
plt.ylabel('茅台日收益 %')
plt.legend()
plt.title('茅台 vs 上证指数（2020-2026 日收益）')
plt.show()

# === 预期输出 ===
样本 1599 个交易日
$\beta$  = 0.886
α（日） = 0.0178% → 年化 4.49%
R^2 = 0.283
:::

读图要点：
- **β≈0.89**：茅台对市场敏感度略低于 1——市场涨 1%，茅台平均涨约 0.89%；
- **R^2≈0.28**：市场因子只解释约 28% 的日收益方差，其余 72% 来自个股自身（非系统风险，可被分散化消除）——这正是 CAPM 说「只有系统风险获得补偿」的实证来源；
- **α**：回归截距，代表「市场解释不了的那部分收益」。年化后若显著为正，就是量化里梦寐以求的 $\alpha$（超额收益）。

## CAPM 的局限与因子模型的诞生

CAPM 简洁漂亮，但假设太强，实证中一个 $\beta$ 解释不了全部收益差异——于是有了**多因子模型**。

CAPM 假设过强：理性投资者、无税无摩擦、同质预期。实证中单个 $\beta$ 无法解释全部收益差异——同一 $\beta$ 的股票收益可以相差很大。

由此诞生多因子模型：
- Fama-French 三因子：市场 + 规模（SMB）+ 价值（HML）；
- 五因子：再加盈利（RMW）+ 投资（CMA）。

CAPM 是一个 $\beta$ 的「单因子模型」。因子模型的本质是把收益来源分解成多个风险因子——Phase 3 会系统学习。

## 练习题

**练习 1（选择题）：** CAPM 的核心思想。

:::quiz
Q: CAPM 的核心思想是?
- 所有风险都能获得补偿
- 只有无法分散的系统风险才获得补偿
- 非系统风险同样能被定价
- $\beta$ 越小，期望收益越高
A: 2
E: 非系统风险可通过分散化消除，市场不为它付费；只有系统风险获得补偿。$\beta=\operatorname{Cov}(R_i,R_m)/\operatorname{Var}(R_m)$。
:::

**练习 2（选择题）：** $\beta$ 的风险含义。

:::quiz
Q: $\beta=0.6$ 的资产意味着?
- 与市场同涨跌
- 波动放大市场的 0.6 倍，属进攻型
- 波动小于市场平均水平，属防御型
- 与市场完全无关
A: 3
E: $\beta<1$ 为防御型（波动弱于市场）；$\beta=1$ 同涨跌，$\beta>1$ 进攻型，$\beta=0$ 与市场无关。
:::

**练习 3（选择题）：** 用 CAPM 计算期望收益。

:::quiz
Q: 无风险利率 3%、市场组合期望收益 10%、某股票 $\beta=1.5$，按 CAPM 其期望收益为?
- 10.5%
- 13.5%
- 15%
- 18%
A: 2
E: $E[R_i]=r_f+\beta(R_m-r_f)=3\%+1.5\times(10\%-3\%)=13.5\%$；$\beta>1$ 放大市场风险溢价。
:::

**练习 4（选择题）：** SML 上资产位置的判断。

:::quiz
Q: 某资产落在 SML 上方，意味着?
- 被低估，实际收益高于 $\beta$ 对应的要求收益，可买
- 被高估，应回避或做空
- 恰好合理定价
- 无法据此判断
A: 1
E: SML 是市场均衡的定价线，线上方表示实际收益高于 CAPM 要求收益（被低估）；下方表示被高估。
:::

**练习 5（应用题）：** CAPM 定价、α 与 SML 位置判断。

:::exercise
T: 无风险利率 $r_f=2\%$，市场组合年化期望收益 $E[R_m]=12\%$。

(1) 按 CAPM 计算 $\beta=0.8$ 的股票 A 的要求收益；

(2) 若 A 实际年化收益为 12%，其 $\alpha$ 是多少？A 落在 SML 上方还是下方？应买入还是回避？

(3) 解释为什么非系统风险在 CAPM 中不获得补偿；

(4) 若市场风险溢价从 10% 升到 12%，A 的要求收益变为多少？说明风险溢价变化如何整体抬高/压低 SML，以及它对「估值中枢」的含义。

:::

**练习 6（选择题）：** 真实 $\beta$ 回归的解读。

:::quiz
Q: 对个股收益做市场回归 $R_i=\alpha+\beta R_m+\varepsilon$，回归斜率代表?
- 个股的非系统风险
- 个股对市场的敏感度 β
- 市场的期望收益
- 个股的特有收益 α
A: 2
E: 回归斜率 $\beta=\operatorname{Cov}(R_i,R_m)/\operatorname{Var}(R_m)$，衡量个股对市场整体变动的敏感度；截距 α 是市场解释不了的部分。
:::

**练习 7（选择题）：** $\beta$ 与 R^2 的含义区分。

:::quiz
Q: 某股票对市场的日收益回归得 $\beta$=0.89、R^2=0.28。下列说法正确的是?
- $\beta$=0.89 意味着市场涨 1% 该股必涨 0.89%
- 市场因子只解释约 28% 的日收益方差，其余来自个股自身（非系统风险）
- R^2=0.28 说明 $\beta$ 估计不可靠，应改用 R^2=1 才可信
- $\beta$>0.5 一定属于进攻型资产
A: 2
E: R^2=0.28 表示市场因子解释约 28% 方差，其余 72% 是非系统风险；$\beta$ 是回归斜率（敏感度），R^2 是解释力，两者不同。
:::

**练习 8（选择题）：** Fama-French 三因子的构成。

:::quiz
Q: Fama-French 三因子模型在 CAPM 的基础上增加了哪两个因子?
- 动量与低波动
- 规模（SMB）与价值（HML）
- 盈利（RMW）与投资（CMA）
- 质量与成长
A: 2
E: 三因子 = 市场 + SMB（规模）+ HML（价值）；五因子再加盈利（RMW）与投资（CMA）。
:::
