## 数据源概览

量化第一步不是研究策略，而是拿到干净的数据。但数据从哪来？市面上有三大免费或低门槛来源：

- **Baostock**：免费、无 token，日线/财务/指数，适合本地量化；
- **Tushare**：数据丰富，积分制；
- **AKShare**：接口最多，稳定性稍差。

QuantLab 底层用 baostock，已同步 10 年 A 股日线到本地 PostgreSQL——本课程主线数据（茅台 2024）即来自这里。

## Baostock 拉取真实数据

三家源里，本项目底层用 **Baostock**——免费、无 token，已同步 10 年 A 股日线到本地 PostgreSQL。下面这段代码直接拉取茅台 2024 的真实日线：

```python
import baostock as bs
import pandas as pd

bs.login()
rs = bs.query_history_k_data_plus(
    'sh.600519',
    'date,code,open,high,low,close,volume,amount,pctChg',
    start_date='2024-01-01', end_date='2024-12-31',
    frequency='d', adjustflag='2')

rows = []
while rs.error_code == '0' and rs.next()：
    rows.append(rs.get_row_data())
df = pd.DataFrame(rows, columns=rs.fields)
bs.logout()
```

`adjustflag=2` 表示**前复权**——处理分红送股，让历史价格可比。

## 复权为什么重要

拿到原始行情后，第一个坑是「除权」。不复权数据在除权日有「假跳空」，导致收益计算错误：
- 除权日价格「凭空下跌」→ 错误的跌幅；
- 历史收益被低估。

**前复权**：以最新价为基准回算历史，当前价不变：**后复权**：以最早价为基准，价格永不回落。量化计算一律用复权价——主线数据的收益都基于复权口径。下方演示可直观看到复权与不复权在除权日的分叉：

:::viz real_vs_log caption=复权与未复权（真实茅台 2024）：三条累计净值曲线——复权累计（主线口径，蓝）、未复权累计（红）、对数收益累计（橙）。6 月分红除权日，复权曲线平滑通过，未复权曲线出现「假跳空」——同一笔分红，两种口径的收益从此分叉。量化计算一律用复权价。
:::

先看**蓝红两条曲线在 6 月的分叉**：复权曲线（蓝）平滑穿过分红除权日，未复权曲线（红）当天出现「假跳空」后从此低于蓝线——同一笔分红，两种口径的累计收益从此不一致，这就是「口径决定结论」。再看**橙色对数收益曲线**：与蓝线几乎重合，说明日频下算术与对数差异可忽略。记住一点：量化计算一律用复权价（蓝线），这是全书的统一口径。

## 数据质量

数据拉下来 ≠ 数据能用。第一件事是检查质量：

```python
df.info()                # 缺失值/类型
df['close'].isnull().sum()  # 停牌日缺失
```

常见问题：停牌日缺失（前向填充）、一字板无量、财报滞后（PIT）。

**真实性原则**：宁可显示「数据缺失」，也不插值掩盖——quantlab 数据是真实行情，缺失即真实缺失。

## 清洗与检查

查出了问题，就要清洗。下面是一条标准流水线：

```python
df['trade_date'] = pd.to_datetime(df['trade_date'])
df = df.sort_values('trade_date').reset_index(drop=True)
df = df.dropna(subset=['close'])   # 去停牌日
df = df[df['close'] > 0]           # 剔异常价
df = df.drop_duplicates(subset=['trade_date'])
```

顺序重要：先排序再算收益，否则 `pct_change` 错位。停牌日缺失是**真实缺失**，不要插值掩盖。

为什么先排序这么关键？因为 `pct_change()` 假设「相邻两行是相邻两个交易日」——数据若按其他顺序（如代码分组、乱序下载）排列，相邻行就不是真实的日线先后关系，算出的收益对不上真实行情。同理，`drop_duplicates` 是为了防止同一交易日出现重复记录（重复拉取、接口重试都可能造成）；`close > 0` 剔除的是异常价（除权前的原始数据可能出现 0 或负值占位）。这条流水线的每一步都在回答同一个问题：**把数据还原成「干净、有序、无重复」的真实日线**，之后所有计算才有意义。

## 收益与指标

数据干净了，就能算收益和指标——这是后面所有策略的原料：

```python
df['ret'] = df['close'].pct_change()
df['ma20'] = df['close'].rolling(20).mean()
df['vol20'] = df['ret'].rolling(20).std() * np.sqrt(252)
df['hh20'] = df['high'].rolling(20).max()  # 唐奇安上轨
df['ll20'] = df['low'].rolling(20).min()   # 唐奇安下轨
```

用复权价算收益（`pct_chg` 复权连乘），年化乘 $\sqrt{252}$。特征工程（去极值/标准化/滞后特征）见 p0-l6。

## 重采样与截面

单只股票的日线算完后，有时要看月线，有时要一次看几百只股票——这需要重采样与截面转换：

```python
# 日 → 月
monthly = df.set_index('trade_date').resample('M').last()
# 多股票截面（每列一只）
pivot = df.pivot_table(index='trade_date', columns='code', values='close')
cross_ret = pivot.pct_change()
```

横截面处理是 Phase 3 多因子分析的基础。

为什么需要这两个操作？**重采样**解决「看多长的时间」：日线噪声大，看月线能滤掉日内波动、看清中期趋势——`resample('M').last()` 取每月最后一个交易日收盘价，得到月线序列。**截面转换**解决「看多少只股票」：单只股票的收益是时间序列（一行一天），但因子分析需要「同一天看很多股票」（每行一天、每列一只股票）——`pivot_table` 做的正是这个转置，转出来后 `pivot.pct_change()` 直接得到全市场横截面的日收益矩阵，这正是第三章多因子横截面检验的输入格式。
