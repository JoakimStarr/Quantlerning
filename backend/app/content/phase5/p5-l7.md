> **学完能做什么：** 独立实现 BS+二叉树+蒙特卡洛统一定价器，附 Greeks 与 VaR；用真实锚点（$\sigma=27.55\%$、$r=3\%$）与「已知答案用例集」交叉验证并自证正确，按报告模板交付，说清从定价器到实盘还差哪些环节。

## 产出目标

本课交付一个**期权定价与风险管理工具**：输入标的价格/执行价/波动率/期限/利率，输出 BS、二叉树、MC 三种价格 + 主要 Greeks + VaR。格式复用前几章产出形态，但核心从「策略/因子」升级为「衍生品定价」。

## 定价器功能

**1. 定价模块**：

- BS 解析解（p5-l2）；
- 二叉树数值解（p5-l3，步数可调，演示收敛）；
- MC 模拟解（p5-l3，路径数可调，演示大数定律）。

三种方法给同一期权定价，误差应随 N/M 增大收敛——这是对「模型一致性」的验证。

**2. Greeks 模块**（p5-l4）：Delta / Gamma / Vega / Theta / Rho，随参数实时更新。

**3. 风险模块**（p5-l6）：对标的真实收益（如茅台 2024）计算参数法/历史法 VaR，输出置信度与持有期可调。

**4. 真实锚点**：

- 波动率 $\sigma$：茅台 2024 年化 **27.55%**（官方口径）；
- 无风险利率 r：LPR 1Y **3.0%**（2026-07 快照）；
- 标的价格 S：茅台实时价（行情查询）。

## 自检清单

- [ ] 三种定价方法结果一致（步数/路径数足够时误差 < 0.05）；
- [ ] Greeks 数值与解析式核对（Delta ∈ (0,1)、平价 Gamma 最大）；
- [ ] VaR 注明方法与置信度（参数法/历史法结果不同是正常的）；
- [ ] 所有模型输入锚定真实数据，示意参数已标注；
- [ ] 报告说明各模型假设与局限（p5-l2/p5-l3 的假设清单）。

## 验收用例集：先写「已知答案」，再谈实现

编码前先把「正确答案已知」的退化情形列成用例集，每写完一个模块就整表跑一遍——任何一条不通过，bug 就在眼前：

| 用例 | 输入 | 期望输出 | 检验谁 |
|---|---|---|---|
| 深度虚值 | $K=200,\ S_0=100$ | 看涨价格 $\to0$（时间价值趋近 0） | BS/二叉树/MC |
| 零波动极限 | $\sigma\to0$、$S_0e^{rT}>K$ | 看涨 $\to S_0-Ke^{-rT}$（只剩折现） | BS 公式 |
| 到期瞬间 | $T\to0$ | 看涨 $\to\max(S-K,0)$（只剩内在价值） | BS/数值法 |
| 零执行价 | $K=0$ | 看涨 $\to S_0$（退化为标的前向价折现） | 三种方法 |
| 平价手工例 | $S_0=K=100,\ T=1,\ r=3\%,\ \sigma=27.55\%$ | 看涨 $\approx12.3$ 元（p5-l2 已手工演算） | 三种方法 |
| 数值收敛 | 二叉树 $N=200$、MC $M=10000$ | 与 BS 误差 $<0.05$ | 数值 vs 解析 |
| Greeks 核对 | 有限差分 vs BS 解析式 | 误差在容忍度内（如 $10^{-2}$） | Greeks 模块 |
| VaR 锚点 | 茅台 2024 日收益 | 参数法 $-2.87\%$、历史法 $-2.42\%$（真实） | 风险模块 |

这张表本身就是「模型一致性」最直接的证据——不是「代码跑通了」，而是**每个模块都能在已知答案上自证**。凡是表里出现过的用例，改完任何代码都要整表重跑；报告应把用例表连同通过记录一起交出去（p5-l6 讲过：这是数值代码的标准自检法）。

## 报告结构模板

产出报告按下面的骨架组织（与 p5-l1~l6 的知识一一对应，避免写成流水账）：

1. **输入与真实锚点**：$\sigma=27.55\%$（茅台 2024 年化波动）、$r=3\%$（LPR 1Y 快照）、$S$（实时查询）——逐个说明数字来源；
2. **三种定价方法与一致性**：BS 解析 / 二叉树（步数收敛演示）/ MC（路径数收敛演示），给出同一参数下的误差表与收敛观察；
3. **Greeks 与风险拆解**：敏感度曲线 + 一句话 P&L 归因（Delta 对冲后赚 Gamma、亏 Theta，p5-l4）；
4. **VaR 报告**：参数法/历史法并排，注明置信度、持有期与样本区间（口径必须写清，p5-l6）；
5. **假设与局限清单**：BS 假设（p5-l2）、数值误差（p5-l3）、微笑与 IV（p5-l5）逐条对照。

每节配一句「看懂什么」，与全书的图注风格一致。

## 里程碑意义

这份定价器是第五章的闭环：从随机过程（p5-l1）到定价公式（p5-l2）到数值方法（p5-l3）到风险管理（p5-l4/p5-l6）。它证明你能**独立实现并交叉验证一个金融模型**——这是从「理解概念」到「动手建模」的跨越。下一阶段（第六章）进入机器学习，把前五章的因子与策略用 ML 自动化。

## 从定价器到实盘：还差什么

定价器是「在给定参数下算出理论价」，而真实期权交易还要补四样：

1. **参数校准**：真实标的不给 $\sigma$，只给报价——你要从市场价格反解隐含波动率、或把模型校准到整张波动率曲面（p5-l5），让定价器吃的是市场当前的波动而不是历史波动；
2. **合约规格与交易规则**：A 股 ETF 期权有合约乘数、最小变动价位、行权价间隔、涨跌停与保证金占用——定价只是前端，合约与风控规则才是落地界面；
3. **对冲成本与离散性**：连续 Delta 对冲在实盘是「多久对冲一次、每次多少成本」的取舍（p5-l4），交易成本与跳空决定对冲频率与残余风险；
4. **对手方与清算**：场内期权有交易所担保与保证金，场外期权要评估对手方信用——模型输出最终要放进一个有规则、有成本、有对手方的世界里才算数。

所以把定价器定位成**计算引擎**而非交易系统：引擎负责「算对」，规则负责「算得能落地」。第五章结束时你拥有的应该是前者，加上对后者的完整认知——第六章之后，第七章会把定价、风控、组合这些零件装进一条从数据到实盘的完整流水线。

## 练习题

**练习 1（选择题）：** 三种方法一致性验证。

:::quiz
Q: 关于定价器「三种方法一致性验证」，下列说法正确的是?
- 任意步数/路径数下三种价格永远相同
- 步数 N 与路径数 M 足够大时，二叉树与 MC 价格应收敛到 BS 解析解，误差小于 0.05
- MC 价格与 BS 价格没有任何可比性
- 二叉树与 BS 价格永远不同
A: 2
E: 三种方法给同一期权定价，误差随 N/M 增大收敛——这是对「模型一致性」的验证（自检清单第一条）。
:::

**练习 2（选择题）：** 三种方法的误差来源。

:::quiz
Q: 关于定价器三种方法的误差来源，下列说法正确的是?
- 二叉树误差主要来自离散化（随 $N$ 增大而减小，通常不单调），MC 误差来自随机采样（随 $M$ 按 $1/\sqrt{M}$ 减小），有限步数/路径数下误差都不会完全归零
- 两者的误差都只来自浮点舍入
- 增大 $N$ 会增大二叉树误差
- 只要 $M$ 足够大，MC 误差可以精确等于 0
A: 1
E: 二叉树收敛到 BS 是离散化误差（震荡收敛）；MC 是采样误差（$1/\sqrt{M}$）。这正是自检清单要求「误差 $<0.05$」而非「$=0$」的原因——模型一致性是「收敛」，不是「逐位相等」。
:::

**练习 3（应用题）：** 定价器综合演练。

:::exercise
T: 定价器综合演练。给定输入 $S_0=K=100$、$T=1$ 年、$\sigma=27.55\%$（茅台 2024 真实年化波动）、$r=3\%$（LPR 1Y 快照）。

① 写出三种定价方法的统一验证步骤：BS 解析解、二叉树（$N=200$）、MC（$M=10000$）应得到近似一致的价格，误差应小于多少？

② 若 MC 结果明显偏离 BS 与二叉树，列出至少两个可能的排查方向；

③ 说明 Greeks 模块中 Delta 与 Gamma 各自回答什么问题，以及为什么平价期权的 Gamma 最大。

④ 设计一个「已知答案」的退化算例检验三个模块的一致性：取 $K=0$，到期收益恒为 $\max(S_T-0,0)=S_T$，由风险中性期望 $\mathbb{E}[S_T]=S_0e^{rT}$ 可知看涨价格应精确等于 $S_0$——解释为什么，并说明若某个模块在该算例下明显偏离 $S_0$，最可能的问题出在哪。


:::answer
- **①** 统一步骤：BS 解析解 → 二叉树（N=200）→ MC（M=10000），三者都定 $S_0=K=100,T=1,\sigma=27.55\%,r=3\%$；误差应 < 0.05（自检清单第一条——「收敛」而非「逐位相等」）。
- **②** 排查方向：MC 随机数种子/路径数不足（采样噪声 $1/\sqrt M$）；二叉树步数太小（离散化误差）；$\sigma$ 单位错（百分比 vs 小数）；折现口径（连续 vs 离散复利）不一致。
- **③** Delta 回答「标的价格动 1 元期权动多少」（方向风险/对冲比率）；Gamma 回答「Delta 本身变多快」（凸性）。平价 Gamma 最大：$\Gamma=N'(d_1)/(S\sigma\sqrt T)$，$N'(d_1)$ 在 $d_1=0$（平价附近）最大——平值处不确定性最大、凸性最强。
- **④** $K=0$：收益恒为 $S_T$，$E^Q[S_T]=S_0e^{rT}$，折现后精确等于 $S_0=100$。若某模块在此算例偏离 100：最可能是折现/增长口径错（如忘了风险中性漂移、或把 $\sigma$ 作用进了均值）——退化算例把「正确答案」唯一化，是三模块交叉验证的锚点。
:::
:::

**练习 4（选择题）：** 验收用例中的零波动极限。

:::quiz
Q: 验收用例 $\sigma\to0$ 时看涨价格趋于 $S_0-Ke^{-rT}$，主要检验 BS 实现的哪一部分?
- 波动率对凸性的定价
- 折现与远期关系的确定性部分
- 随机数生成质量
- Greeks 的计算
A: 2
E: 波动率归零后期权退化为「折现后的远期差价」，该用例钉住折现/利率部分；凸性部分由深度虚值趋 0、平价手工例等用例检验。
:::

**练习 5（选择题）：** VaR 报告的必备口径。

:::quiz
Q: 按报告模板交付 VaR 模块时，以下哪项是必须写明的?
- 只报告历史法一种结果
- 方法、置信度、持有期与样本区间，参数法/历史法并排互证
- 只报告最乐观的一种方法
- 口径可以省略
A: 2
E: 尾部假设不同 → 三法结果不同是常态；报告必须注明方法、置信度、持有期与样本区间，最好多法同报互证（p5-l6）。

**练习 6（选择题）：** 从定价器到实盘的关键补充。

:::quiz
Q: 把本课定价器用到真实期权交易，最关键的前置工作是?
- 直接用历史波动率代替市场波动率
- 从市场报价反解隐含波动率/校准曲面，并纳入合约规格、对冲成本与清算规则
- 修改 BS 公式本身
- 不需要任何补充
A: 2
E: 实盘标的不给 $\sigma$ 只给报价——要反解 IV/校准曲面让模型吃市场当前波动；还要补合约规则、对冲成本与对手方清算等落地环节。
:::

**练习 7（应用题）：** 验收用例集设计与数值退化诊断。

:::exercise
T: 给定 $S_0=K=100$、$T=1$ 年、$r=3\%$（LPR 1Y）、$\sigma=27.55\%$（茅台 2024 真实年化波动）。

① 平价例 BS≈12.3：二叉树（$N=200$）与 MC（$M=10000$）落在什么范围算通过？若 MC 给出 12.4，是正常还是 bug？依据是什么？

② K=0 例三项均应约为 100，$\sigma\to0$ 例 BS 应约为 3.0——这两个退化用例各主要检验定价器的哪一部分？

③ 数值退化：把 $u=e^{\sigma\sqrt{\Delta t}}$、$d=1/u$、$p=\frac{e^{r\Delta t}-d}{u-d}$ 代入 $\sigma\to0$，说明 $u,d,p$ 各发生什么、为什么直接跑二叉树会数值崩溃，实践中应如何处理？

④ 写出报告中至少 3 句「看懂什么」式的一行观察。

:::answer
- **①** 按自检清单误差应 $<0.05$，即落在约 $[12.25,12.35]$。MC=12.4 属正常：MC 是采样估计，误差 $O(1/\sqrt M)$，$M=10000$ 下单次运行波动约 ±0.1~0.2 属预期（换种子/加大 M 会改善）；若持续偏离 BS 超过 0.3 才应怀疑 bug。
- **②** K=0 例把答案唯一化为 $S_0=100$，检验风险中性折现与漂移口径（把 $\sigma$ 错误作用进均值会立刻偏离）；σ→0 例把价格唯一化为 $S_0-Ke^{-rT}\approx3.0$，检验折现/利率部分与「波动率只通过凸性起作用」的实现。
- **③** $\sigma\to0$ 时 $u=e^0=1$、$d=1/u=1$，所有节点重合，树退化成一条线，无法再表达「上/下」两种未来；风险中性概率 $p=\frac{e^{r\Delta t}-d}{u-d}$ 的分母 $u-d=0$（分子 $e^{r\Delta t}-1>0$），$p$ 发散、无定义——直接运行会出现除零或 NaN。实践处理：对 $\sigma$ 设数值下限、σ→0 时特判改用解析式（期权退化为远期差价 $S_0-Ke^{-rT}$）、或在用例表里标注该输入不适用二叉树。
- **④** 例如：「平价期权价格几乎全部是时间价值」「σ→0 时期权退化为远期差价，凸性随之消失」「MC 误差随路径数按 $1/\sqrt{M}$ 收敛、不是逐位相等」「K=0 退化例把漂移口径唯一化，是回测漂移 bug 最快的探针」。
:::
:::

## 本章生态：衍生品定价与风险管理生态

第五章的定价器在行业里有专业级的对应物：

- **开源定价库**：QuantLib（衍生品定价的业界标准开源库，BS/二叉树/MC/Heston/Greeks 全齐，C++ 内核带 Python 绑定）、py_vollib（纯 Python 的 IV/Greeks 计算，轻量）、Financial Mathematics Python（教学向）；
- **波动率数据**：真实期权行情需要专门的波动率数据服务——iVolatility、OptionMetrics（学术/机构）、券商柜台提供的 IV 曲面快照；A 股期权（50ETF、300ETF）的行情可在券商客户端或聚宽/米筐等平台获取；
- **风险管理系统**：券商/机构的 VaR 引擎（基于历史模拟或蒙特卡洛）、OpenGamma 开源风险平台——p5-l6 的参数法/历史法/MC 正是这类系统的三种实现；
- **实盘期权交易**：A 股期权需开通期权账户并满足适当性要求；程序化期权交易通常走券商的期权交易 API（如中金所接口、券商柜台），国内个人量化以研究定价与 Greeks 管理为主。

第五章的价值在于「把定价与风险管理的数学讲透」——QuantLib 这类库能算得更快更全，但看不懂输出背后的假设，就无法判断它算得对不对。
