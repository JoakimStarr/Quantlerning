## 定义

模型是特征到标签的函数族。选择模型 = 选择这个函数族的**表达力**与**归纳偏置**：

- 逻辑回归：线性决策面 $\sigma(w^\top x + b)$，可解释，适合特征少、关系近似线性时；
- 决策树 / 梯度提升树（XGBoost、LightGBM）：非线性、自动处理交互与缺失，是表格数据的强基线；
- 神经网络（LSTM 见 p5-l6）：能建模序列依赖，但数据量需求大、可解释性弱。

:::quiz
Q: 逻辑回归的决策面具有什么特点?
- 非线性的深度结构
- 线性决策面 $\sigma(w^\top x+b)$，可解释，适合特征少、关系近似线性时
- 自动处理缺失值与特征交互
- 能建模序列依赖
A: 2
E: 逻辑回归是线性决策面、可解释性强;决策树/梯度提升树才具备非线性与自动处理交互的能力。
:::

## 训练：梯度下降

无论哪种模型，核心是优化损失函数。逻辑回归用梯度下降迭代更新权重：

$$w \leftarrow w - \eta \frac{\partial \mathcal{L}}{\partial w}$$

学习率 $\eta$ 过大震荡、过小收敛慢。梯度下降的方向——沿负梯度——与第三章最优化直觉一致，第五章直接用前面的梯度场可视化理解它。

:::viz gradient_field caption=梯度场演示：f(x,y) 的高度图（颜色）+ 各点梯度箭头。梯度 ∇f 指向上升最快的方向，训练即沿负梯度反复移动——每次迭代权重都向损失更小的方向调整一步。
:::

:::quiz
Q: 学习率 $\eta$ 过大对梯度下降的影响是?
- 收敛更快且更稳定
- 权重更新震荡，难以收敛
- 没有任何影响
- 损失必然降为 0
A: 2
E: 更新式 $w\leftarrow w-\eta\frac{\partial \mathcal{L}}{\partial w}$ 中 $\eta$ 过大步长太大导致震荡;过小则收敛慢。
:::

## 特征重要度

树模型给出特征重要度（分裂收益的累积），线性模型给出标准化权重。**绝对值越大 → 特征越重要，正负号 → 影响方向**。这是 ML 给量化最重要的礼物之一：让机器告诉我们哪些因子（第三章 161 个）真正有用。

:::viz feature_importance caption=特征重要度模拟器：在茅台 2024 真实 8 个技术特征上训练逻辑回归（时间顺序切分、L2 正则可调）。柱状图为标准化权重 |w|，红色=负向（特征越大次日越可能跌），蓝色=正向。教学点：重要度帮我们排除噪音特征。
:::

:::quiz
Q: 线性模型中，标准化权重的含义是?
- 绝对值越大特征越重要，正负号表示影响方向
- 绝对值越大特征越不重要
- 权重正负号表示收益率高低
- 权重与特征重要度无关
A: 1
E: 标准化权重 $|w|$ 越大特征越重要，符号表示影响方向——让机器告诉我们哪些因子真正有用。
:::

## 金融应用

- 逻辑回归 = 多因子线性打分（第三章因子合成的 ML 版本）；
- XGBoost/LightGBM = 非线性因子组合，能捕捉「因子只在某些市况下有效」的交互；
- **可解释性取舍**：线性模型权重直接映射因子暴露；树模型重要度是汇总指标。实盘决策需要可解释性，这是模型选择的隐性约束。

:::quiz
Q: 为什么实盘决策中常优先选择逻辑回归这类线性模型?
- 因为它总是预测最准
- 因为其权重直接映射因子暴露，可解释性强
- 因为它不需要数据
- 因为它从不发生过拟合
A: 2
E: 线性模型权重直接映射因子暴露，可解释;树模型的重要度是汇总指标，实盘决策需要可解释性是模型选择的隐性约束。
:::

## 局限

- 非线性模型拟合能力强 → 更容易过拟合（下一课）；
- 金融信噪比低，非线性收益在样本外常不显著；
- 模型复杂 → 参数多 → 对数据量与正则更敏感。

:::quiz
Q: 非线性模型在金融中的主要风险是什么?
- 训练速度一定更慢
- 拟合能力强 → 更容易过拟合，样本外非线性收益常不显著
- 需要更少的训练数据
- 参数比线性模型更少
A: 2
E: 非线性模型拟合能力强、参数多，更容易过拟合;金融信噪比低，非线性收益在样本外常不显著。
:::

## 练习题

**练习 1（选择题）：** 学习率过大对梯度下降的影响是？

:::quiz
Q: 更新式 $w\leftarrow w-\eta\frac{\partial\mathcal{L}}{\partial w}$ 中，学习率 $\eta$ 过大会导致?
- 收敛更快且稳定
- 权重更新步长过大，来回震荡、难以收敛
- 没有任何影响
- 损失必然降为 0
A: 2
E: $\eta$ 过大时步长太大，权重越过最优点来回震荡；$\eta$ 过小则收敛缓慢。
:::

**练习 2（选择题）：** 需要向风控同事解释「模型到底在学什么」时，应优先选哪类模型？

:::quiz
Q: 特征少、关系近似线性且需要可解释性时，应优先选择?
- LSTM
- 深随机森林
- 逻辑回归
- 任意模型均可
A: 3
E: 逻辑回归决策面线性、权重直接映射因子暴露，可解释性强，适合特征少、关系近似线性的场景，实盘决策常优先。
:::

**练习 3（应用题）：** 手算一步梯度下降，并体会学习率的作用。

:::exercise
T: 逻辑回归对单个样本的损失关于权重 $w_1$ 的偏导为 $\frac{\partial\mathcal{L}}{\partial w_1}=0.3$。设当前 $w_1=1.0$、学习率 $\eta=0.1$，请计算一步梯度下降后的 $w_1$。再讨论：若把 $\eta$ 调成 5，一步后 $w_1$ 会变成多少（设最优点在 0 附近）？这与「$\eta$ 过大震荡」有什么关系？追问：若加入 L2 正则 $\mathcal{L}'=\mathcal{L}+\lambda\sum_j w_j^2$，写出 $\partial\mathcal{L}'/\partial w_1$ 比原来多出的项，并说明它如何每步把权重拉向 0；当 $\lambda$ 很大而真实信号弱（茅台日频低信噪比）时，权重会偏向什么结果？
:::

**练习 4（选择题）：** 用训练/测试差距诊断模型选择。

:::quiz
Q: 同一份茅台 2024 数据（时间切分）上，逻辑回归训练/测试 AUC 为 0.65/0.60，XGBoost 为 0.99/0.52。最合理的结论是?
- XGBoost 更好，应直接实盘使用
- 逻辑回归泛化更稳定；XGBoost 在低信噪比小样本上明显过拟合，测试 AUC 0.52 接近随机
- 两者都不行，应换 LSTM
- AUC 反映不出过拟合
A: 2
E: 训练与测试差距大 = 过拟合（p5-l5）；非线性强模型在金融低信噪比、样本少（约 240 个日样本）下极易记住噪音，测试 AUC 0.52 已无预测力。
:::
