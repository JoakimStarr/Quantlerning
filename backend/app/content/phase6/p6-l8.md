> **学完能做什么：** 独立完成 ML 策略对比实验：特征→标签→模型→回测全链路，验证「模型有用 ≠ 策略赚钱」。

## 完整管线

第六章的可视化组件恰好构成一条可操作的 ML 量化链路：

1. **特征工程**（p6-l2）：茅台真实行情 → 8 个技术特征（动量/波动/RSI/MACD/均线偏离/换手），时间对齐杜绝前视；
2. **标签设计**（p6-l3）：次日涨跌二分类标签；
3. **模型训练**（p6-l4）：逻辑回归 + 梯度下降 + L2 正则（特征重要度图展示模型学到了什么）；
4. **评估**（p6-l5 / p6-l7）：时间顺序切分、训练/验证误差、IC 与分类指标；
5. **回测对比**（本章）：ML 信号 vs 传统双均线 vs 买入持有。

这条链路不是五个孤立的演示，而是一个**层层递进的决定链**：特征工程决定「模型能看到什么」，标签设计决定「目标是什么」，模型选择决定「用什么函数逼近」，评估决定「是否可信」，回测决定「赚不赚钱」。前一环的输出就是后一环的输入——这也是为什么第六章要按 l2→l8 的顺序推进：**任何一环设计错误，都会沿着链路传导到最终结论**。比如标签用了未复权收益（p6-l3），再好的特征和模型也会在回测里失真。

## ML vs 传统策略

:::viz ml_backtest caption=阶段产出：ML 策略对比模拟器。前段（训练占比可调）训练逻辑回归，后段测试（信号次日生效）。三种净值曲线同台对比 + 完整绩效表（累计/年化/波动/夏普/回撤/持仓）。教学点：没有免费的午餐——ML 在单只股票上未必赢均线，这本身就是要学会的教训。
:::

**先看三条曲线的收尾高度**：在这个真实样本上，ML（逻辑回归）未必显著高于双均线或买入持有——这不是组件 bug，而是第六章的核心结论「模型有用 ≠ 策略赚钱」的直观呈现：单只股票、约 240 个日样本、低信噪比，正是 ML 最不占优的场景。**再看绩效表**：三者的夏普、回撤差距远小于「训练集上准确率的差距」——说明训练集上的漂亮指标在样本外被大幅稀释。**最后拖动训练占比**：训练占比越小，测试段越短，三条曲线的结论越不稳定——这呼应 p3-l5 的「回测是样本估计，样本越短越不可信」。

## 阶段总结

第六章的全部教训可以浓缩为三条：

1. **数据纪律优先**：特征与标签的每一处前视泄漏，都会把回测变成幻觉（p6-l2、p6-l3）；
2. **过拟合是头号敌人**：交叉验证、正则、早停，外加时间切分，是保命四件套（p6-l5）；
3. **以回测为准**：准确率、IC 都是中间指标，净值曲线与风险调整收益才是最终裁决（p6-l7）。

这三条不是并列的清单，而是一个**因果链**：数据纪律出了问题，过拟合防线再严也会学错对象；过拟合没防住，评估数字再漂亮也是虚的；评估没做对，回测结论自然不可信。所以「以回测为准」不是最后一步，而是对前三步的总检验——**任何一步放松，最终净值都会说真话**。

## 下一步

第七章组合优化把单标的策略升级为组合配置：马科维茨有效前沿、风险平价、Black-Litterman。ML 预测（本章产出）将作为组合的**收益预测输入**——预测准不准，最终由组合层的分散化来检验。这也是为什么量化管线的最后一段永远是「组合 + 风控」。

## 本章生态：机器学习量化生态

第六章用纯 TypeScript 手写逻辑回归教学——行业里的 ML 量化用更完整的工具链：

- **数据与特征层**：Microsoft Qlib（数据→因子→模型全链路，内置 A 股数据与算子）、聚宽 JQData / 米筐 rqdatac（ML 特征常用数据源）、自建因子库（第四章的因子即特征）；
- **模型层**：XGBoost / LightGBM（表格数据强基线，本书第六章正文推荐）、scikit-learn（教学与基准）、PyTorch / TensorFlow（深度学习，LSTM/Transformer 类模型）、statsmodels（时间序列与统计检验）；
- **特征与因子开源库**：Alphalens（因子分析）、TA-Lib / pandas-ta（技术指标算子）、qlib 的算子框架（自动特征组合）——本课的 8 个技术特征在这些库里都有现成算子；
- **社区与赛事**：Kaggle 金融类比赛、WorldQuant 挑战赛、Qlib 社区、知乎量化专栏、`awesome-machine-learning-for-trading` GitHub 清单——第六章的「逻辑回归手写」是理解这些工具的第一步，理解后再用现成库才不是黑箱。

第六章的核心立场——「模型有用 ≠ 策略赚钱」——在真实 ML 量化圈同样是反复被验证的教训：工具在进化，但数据纪律、过拟合、以回测为准这三条铁律不变。
