> **前置知识：** 第六章 p6-l1~l7 全部（特征/标签/模型/过拟合/评估）。
> **学完能做什么：** 设计一个对照组齐全、口径统一的 ML 策略对比实验；读懂净值/夏普/回撤/换手的对比表；按八条验收清单自证结论可信，并写出可交付的实验报告。

## 主线：把前七课做成一次可复核的实验

前七课各交付了一环：特征（p6-l2）、标签（p6-l3）、模型（p6-l4）、过拟合防线（p6-l5）、深度与 RL 的边界（p6-l6）、评估语言（p6-l7）。这一课把它们串成**一次完整的实验**——用茅台 2024 真实日线训练一个 ML 信号，与两个最朴素的对手同台比较：**双均线**（人写规则的代表）与**买入持有**（什么都不做的基准）。

先说清楚这一课的成败标准：**不是为了证明 ML 更强**。恰恰相反，在这个场景（单只股票、约 220 个可用样本、低信噪比）里，ML 常常赢不了均线——那是 p6-l4「复杂在金融常是诅咒」的应有结果。真正的产出是：**你能证明这个结论是干净的**。也就是说，输要输得明白（知道输在样本、频率还是成本），赢也要经得起八条验收清单的拷问。

## 完整管线与每环的失败模式

第六章的可视化组件本身就是一条可操作的 ML 量化链路，每一环都有它特有的失败模式：

| 环节 | 交付什么 | 典型失败模式 |
|---|---|---|
| **特征工程**（p6-l2） | 8 个技术特征（动量/波动/RSI/MACD/均线偏离/换手） | 混入未来信息、统计量含测试集、特征高度冗余 |
| **标签设计**（p6-l3） | 次日涨跌二分类（$h=1$、$\theta=0$） | 未复权收益、极端阈值导致类别崩塌、前瞻期与切分不留缓冲 |
| **模型训练**（p6-l4） | 逻辑回归 + 梯度下降 + L2 正则 + 早停 | 容量超样本承受力、学率过大震荡、重要度被误读为因果 |
| **评估**（p6-l5/l7） | 时间切分、训练/验证误差、IC 与分类指标 | 测试集反复调参、只看准确率、多重检验未校正 |
| **回测对比**（本课） | ML vs 双均线 vs 买入持有 | 口径不统一（成本/成交价/收益口径）、信号当日生效、交易次数被忽略 |

这条链路不是五个孤立演示，而是一条**层层传导的决定链**：特征决定模型能看到什么，标签决定目标是什么，模型决定用什么函数逼近，评估决定结论是否可信，回测决定赚不赚钱。**前一环的任何错误都会沿链路传导到最终结论**——比如标签用了未复权收益（p6-l3），再好的特征和模型都会在回测里失真。

## 实验设计：对照组与统一口径

一次可信的对比实验至少要设计三组，缺一组结论就站不住：

1. **ML 策略**：逻辑回归预测次日上涨概率 → 概率超过阈值则次日满仓、否则空仓（**信号次日生效**）；
2. **双均线**：MA20 上穿 MA60 买入、下穿卖出（第三章的人工规则基线，同样次日生效）；
3. **买入持有**：全程满仓（「什么都不做」的基准，用来回答「折腾一圈值不值」）。

统一口径比模型本身更重要，四条必须写进实验说明：

- **同一段真实数据**：茅台 2024 全年份，前段训练、后段测试（时间顺序，比例可调）；
- **同一成本假设**：单边成本（佣金+滑点）按 p3-l7 的量级统一设置，三条策略一视同仁；
- **信号次日生效**：今天收盘出信号、明天以收盘价成交（杜绝「用收盘价算信号又按收盘价成交」的不可实现假设）；
- **同一绩效口径**：累计/年化/波动/夏普/回撤按第一章与第三章的官方口径计算（复利连乘、几何年化、ddof=1），三策略同表对比。

:::viz ml_backtest caption=阶段产出：ML 策略对比模拟器。前段（训练占比可调）训练逻辑回归，后段测试（信号次日生效）。三种净值曲线同台对比 + 完整绩效表（累计/年化/波动/夏普/回撤/持仓）。教学点：没有免费的午餐——ML 在单只股票上未必赢均线，这本身就是要学会的教训。
:::

**先看三条曲线的收尾高度**：在真实样本上，ML（逻辑回归）未必显著高于双均线或买入持有——这不是组件 bug，而是「模型有用 ≠ 策略赚钱」的直观呈现。**再看绩效表**：三者的夏普与回撤差距，通常远小于它们在「训练集准确率」上的差距——训练集上的漂亮指标在样本外被大幅稀释，这正是 p6-l5 过拟合与 p6-l7 评估要提前拦截的东西。**最后拖训练占比**：占比越小，训练样本越少、测试段相对越长，三条曲线的排序越不稳定——呼应 p3-l5「回测是样本估计，样本越短越不可信」。读这张图的正确姿势是**先看差距是否稳定、再看谁高**，而不是只比终点高度。

## 结果怎么读：指标表与「差距 vs 噪声」

对比表至少要包含这些列，缺一列都可能误判：

| 指标 | 回答什么 | 为什么必须在表里 |
|---|---|---|
| 累计/年化收益 | 赚了多少 | 最终裁决（几何年化口径） |
| 年化波动 | 波动多大 | 收益必须用风险归一化 |
| 夏普 | 每单位风险换多少收益 | 三策略横向可比的核心指标 |
| 最大回撤 | 最坏那一段多痛 | 决定能否拿得住 |
| 持仓占比/交易次数 | 多久在场、多频繁 | 暴露换手成本与容量约束 |
| 测试段 IC / AUC | 预测力有没有 | 区分「不赚钱是因为没预测力」还是「有预测力但被成本吃掉」 |

读表的关键判断是**差距是否大于噪声**：单只股票、几十次交易的小样本里，年化收益差几个百分点往往分不出是实力还是运气。这时候要看三件事——交易次数够不够多、测试段够不够长、换个切分比例结论是否还在（稳健性）。**结论会随切分比例翻转的实验，等于没有结论。**

## 报告模板

一次 ML 策略对比实验，报告按六节写（与 p5-l7 的产出规格一致）：

1. **数据与口径**：标的、区间、复权口径、特征预热期剔除、样本量（训练/验证/测试各多少）；
2. **实验设计**：特征清单与构造式、标签定义（$h$、$\theta$）、模型与正则、对照组、成本假设、信号生效方式；
3. **结果**：三策略绩效表 + 净值曲线 + 测试段 IC/AUC；
4. **稳健性**：换切分比例、换阈值、换随机种子后结论是否保持；
5. **失败模式排查**：逐条对照下面八条验收清单，写明每条的排查结论；
6. **结论与局限**：说清「赢/输在哪」，以及样本、频率、容量上的限制。

## 八条验收清单（防自欺）

做完实验逐条打勾，任何一条不过，结论就不许往外讲：

- [ ] 行情用**复权价**、收益用复利连乘口径（p1-l8）；
- [ ] 每个特征只用 $t$ 及之前的信息，抽查任一天验证（p6-l2）；
- [ ] 标准化/去极值的统计量**只从训练集**计算（p6-l2）；
- [ ] 标签前瞻期 $h$ 与切分缓冲匹配，$h>1$ 时留出至少 $h$ 天（p6-l5）；
- [ ] 训练/验证/测试三层，测试集**只碰一次**（p6-l5/p6-l7）；
- [ ] 信号**次日生效**、成交价与成本假设与对照组**完全一致**（p3-l7）；
- [ ] 报告了**训练与验证的差距**，且没有只看准确率（p6-l7）；
- [ ] 记录了**试验次数**（换过几次特征/参数/阈值），并对最优结果打折解读（p6-l5 选择偏差）。

## 为什么 ML 未必赢，以及它什么时候更可能有优势

把机制讲清楚，比争论「ML 有没有用」更有价值。ML 在这个实验里吃亏的四条机制：

1. **样本太少**：约 220 个可用样本撑不起模型自由度，双均线的规则是「人先验写死的」，等于自带正则；
2. **信噪比太低**：真信号弱（p4 实测 PE 因子 Rank IC 仅 0.016），模型容易把噪音学成规律；
3. **成本与换手**：ML 信号切换更频繁，精确率不足时成本吃掉边际优势（p6-l7 的期望收益公式）；
4. **单标的没有横截面信息**：多因子选股能吃「股票之间的相对强弱」，单股择时只能吃时序那一点点自相关。

反过来，ML 更可能有优势的地方也很清楚：**多资产横截面**（样本随股票数放大，正是因子的主场）、**分钟级高频**（样本随频率放大）、**高维特征与交互**（人写不出规则的关系）、**多步决策**（仓位与执行，p6-l6 的 RL）。所以正确的期待不是「ML 一定赢均线」，而是**「在数据密度与任务复杂度支撑得起容量的地方，ML 才值得上」**。

## 阶段总结：第六章的三条铁律

1. **数据纪律优先**：特征与标签的每一处前视泄漏，都会把回测变成幻觉（p6-l2、p6-l3）；
2. **过拟合是头号敌人**：交叉验证、正则、早停，外加时间切分，是保命四件套（p6-l5）；
3. **以回测为准**：准确率、IC 都是中间指标，净值曲线与风险调整后收益才是最终裁决（p6-l7）。

三条不是并列清单，而是一条**因果链**：数据纪律出了问题，防线再严也学错对象；过拟合没防住，评估数字再漂亮也是虚的；评估没做对，回测结论自然不可信。**任何一步放松，最终净值都会说真话**。

## 下一步：从单标的到组合

第七章把单标的策略升级为**组合配置**：马科维茨有效前沿、风险平价、Black-Litterman。本章的 ML 预测将成为组合层的**收益预测输入**——预测准不准，最终由组合层的分散化来检验。这也是为什么量化管线的最后一段永远是「组合 + 风控」：单标的的胜负可能来自运气，组合层的稳定才来自结构。

**练习 8（应用题）：** 设计一个最小可验证的 ML 策略实验。

:::exercise
T: 基于贵州茅台 SH600519 2024 真实日线，设计一个最小可验证的 ML 策略实验：特征（任选 3 个并写构造式）、标签、训练/测试切分、评估指标、对照组。若测试段年化低于双均线，是否说明 ML 无用？

追问一：构造一个使该策略「回测虚高、实盘失效」的具体场景，并说明可提前用什么手段发现；
追问二：切分比例从 70/30 改为 50/50，对过拟合风险与评估的统计显著性各有什么影响？

:::answer
- **主答**：特征 = 5 日动量 $C_t/C_{t-5}-1$、20 日波动 $\text{std}(r_{t-19..t})$、RSI(14)（均只用 $t$ 及之前信息）；标签 = 次日涨跌（$h=1,\theta=0$）；切分 = 前 70% 训练、后 30% 测试（时间顺序，$h=1$ 至少留 1 天缓冲）；指标 = 测试段 IC/AUC + 净值对比买入持有；对照组 = 双均线 + 买入持有。跑输双均线 ≠ ML 无用：单标的 + 约 220 样本 + 低信噪比正是 ML 最不占优的场景，实验检验的是**流程正确性**而非「ML 必然更强」。
- **追问一**：示例——某特征的时间对齐错误（如把 $t+1$ 的收盘价混进动量），回测会虚高。提前发现手段：① 训练/验证误差差距监控（学习曲线）；② 特征时间对齐审计（抽查几天，逐列验证只含 $t$ 及之前信息）；③ 训练/测试段市场状态对比（波动率、趋势统计）。
- **追问二**：70/30→50/50：训练样本减少（如 169→121），**过拟合风险上升**（更少样本撑同样的自由度）；测试段变长但训练不稳，且单段测试样本本就少——**评估的统计显著性下降**，更难区分噪声与信号。
:::

**练习 9（应用题）：** 诊断一个「看起来很成功」的对比实验。

:::exercise
T: 某研究员报告：ML 策略测试段年化 28%、夏普 1.6、准确率 68%，明显跑赢双均线（年化 6%）与买入持有（年化 -6%）。已知他做了这些事：① 用未复权价算收益；② 信号当日收盘生成并按当日收盘成交；③ 为了让结果更好，换了 40 组参数后选最优；④ 成本只算了佣金、没算滑点；⑤ 训练与测试按交易日随机切分。

① 逐条指出每个问题会如何影响结论（夸大/失真方向）；
② 给出修正后的正确做法（对应到本课八条验收清单）；
③ 修正后若 ML 仍跑赢，还需要补什么稳健性检验才能下结论？

:::answer
- **①** ① 未复权价：除权日跳空制造虚假涨跌，标签失真，模型学伪信号；② 信号当日生效：用收盘价算信号又按收盘价成交，不可实现，年化系统性虚高；③ 换 40 组参数选最优：选择偏差，最优结果被运气撑高（$1-0.95^{40}$ 量级的假阳性风险）；④ 只算佣金：低估成本，高换手的 ML 策略被高估最多；⑤ 随机切分：未来信息泄漏进训练，测试误差被严重低估。
- **②** 修正：复权价 + 复利连乘口径；信号次日生效；训练/验证/测试三层、测试只碰一次、记录试验次数；成本含佣金+滑点（与对照组一致）；时间顺序切分并留出前瞻期缓冲——正好对应八条验收清单中的第 1、5、6、7、8 条。
- **③** 还需：换切分比例（70/30 ↔ 60/40）看结论是否保持；换阈值与随机种子；换时间段/标的做外部验证；报告交易次数与持仓占比，确认收益不是来自少数几天或极端杠杆；最后对照「差距是否大于噪声」。

## 本章生态：机器学习量化生态

第六章用纯 TypeScript 手写逻辑回归教学——行业里的 ML 量化用更完整的工具链：

- **数据与特征层**：Microsoft Qlib（数据→因子→模型全链路，内置 A 股数据与算子）、聚宽 JQData / 米筐 rqdatac（ML 特征常用数据源）、自建因子库（第四章的因子即特征）；
- **模型层**：XGBoost / LightGBM（表格数据强基线）、scikit-learn（教学与基准）、PyTorch / TensorFlow（深度学习，LSTM/Transformer 类模型）、statsmodels（时间序列与统计检验）；
- **特征与因子开源库**：Alphalens（因子分析）、TA-Lib / pandas-ta（技术指标算子）、Qlib 算子框架（自动特征组合）——本课的 8 个技术特征在这些库里都有现成算子；
- **社区与赛事**：Kaggle 金融类比赛、WorldQuant 挑战赛、Qlib 社区、`awesome-machine-learning-for-trading` GitHub 清单——第六章的「逻辑回归手写」是理解这些工具的第一步，理解后再用现成库才不是黑箱。

第六章的核心立场——「模型有用 ≠ 策略赚钱」——在真实 ML 量化圈同样是反复被验证的教训：工具在进化，但数据纪律、过拟合、以回测为准这三条铁律不变。
