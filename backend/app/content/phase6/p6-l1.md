> **前置知识：** p3-l0~l1 策略三要素（人工规则）；p4-l1 因子与 APT（特征与打分）；p0-l6 Python。
> **学完能做什么：** 说清监督/无监督/强化三类范式各自学什么、怎么评估；把「用茅台 2024 真实日线预测次日涨跌」完整映射到监督学习形式化；说出金融数据四条「让 ML 更难」的特性及其后果。

## 主线：第六章在把什么「自动化」

前三章的策略是人写的规则：MA20 上穿 MA60 就买——周期、方向、阈值全部由人定。第四章往前走了一步：因子（如 PE、动量）是**人设计的特征**，但「特征值高的组是否涨得更好」已经交给统计检验去回答——规则的一半开始让数据说话。第六章再走最后一步：**连「特征怎么组合、规则长什么样」也交给算法从数据里学**。这就是机器学习在量化里的全部含义——不是魔法，而是「把决策规则从显式变成隐式」的一次委托。

这次委托有一个必须记住的代价：人写的规则错了，你**知道**它错在哪（回测、复盘、改参数）；数据学出来的规则错了，你可能**不知道**它错在哪——它在训练集上看起来好极了。所以第六章的所有内容都围绕同一件事：**怎么防止机器学错，以及学错了怎么发现**。这一课先把「学什么、怎么学、为什么难」的地图铺开。

## 规则从谁手里来：一条光谱

把前三章到第六章连起来看，是一条「规则来源」的光谱，而不是几个并列的流派：

| | 人工规则（p3） | 因子打分（p4） | 机器学习（p6） |
|---|---|---|---|
| 谁定规则 | 人 | 人定特征、数据定权重 | 数据定特征组合与规则 |
| 规则形态 | 显式条件（金叉买入） | 单变量线性打分 | 多特征（线性/非线性）组合 |
| 可解释性 | 完全可解释 | 可解释 | 随复杂度下降 |
| 换一个思路的成本 | 重写规则 | 加一个因子重检验 | 换模型/换特征重训练 |

光谱的连续性值得注意：**第四章的「单因子检验」，严格说就是一个只有单一特征 $x$、输出打分 $f(x)$ 的监督模型**——IC、分层收益检验的正是这个 $f$ 有没有预测力。机器学习没有引入任何全新的哲学，它只是把这条光谱推到底：特征从 1 个变成几十个，$f$ 从打分变成任意函数，权重从人拍板变成最优化解出。理解了「光谱」而非「门派」，后面每一课都会更顺。

## 三类范式：按「反馈来源」一次分清

机器学习按**学习信号从哪来**分三类。这个分法比死记名字重要得多，因为它直接决定了「怎么评估一个模型」：

- **监督学习**（supervised）：每个样本带**正确答案**（标签），学 $x\to y$ 的映射。反馈来自标签——所以评估看「预测对不对」。量化里预测次日涨跌（分类）、预测收益率（回归）都属此类，是**第六章主线**；
- **无监督学习**（unsupervised）：没有标签，只给一堆 $x$，学数据**内部的结构**。反馈来自结构本身——评估看「分组/降维稳不稳、是否有意义」。量化里：用聚类把全市场股票按风格分组，用 PCA 把几十个相关因子压成几个正交成分（呼应 p4 因子去相关）；
- **强化学习**（reinforcement learning）：没有正确答案，只有一个**环境**和**延迟的奖励**——智能体做动作、看结果、学策略。反馈来自「多步之后累计奖励」。评估看「累积收益/风险调整后收益」。量化里最自然的位置是**仓位与执行**（什么时机买多少、怎么拆单），而不是「明天涨不涨」这种单步预测。

一句话记忆：**监督看正确答案，无监督看数据结构，强化看延迟奖励**。用三条例子对比：茅台次日涨跌是监督（有标签）；把 5000 只股票聚成风格簇是无监督（无标签）；一个 agent 决定今天满仓还是半仓、等一周后看结果，是强化（延迟奖励）。

## 形式化：监督学习到底在解什么

监督学习把「找规律」写成一道最优化题。设样本 $(x_i,y_i)$、模型 $f$、损失函数 $\ell$：

$$\min_f\;\mathbb{E}[\;\ell(y,f(x))\:]$$

逐层拆开这道式子的三个词，就是整个第六章的目录：

1. **$f$（模型）**：你在允许「哪些形状的规则」里找答案。线性回归只允许直线，逻辑回归允许一条 S 形曲线，决策树允许分段常数，神经网络允许任意光滑函数——$f$ 的灵活度叫**模型容量**，容量太大是 p6-l5 过拟合的源头；
2. **$\ell$（损失）**：怎么度量「错了多少」。分类错一次记 1（0-1 损失），但更常用**交叉熵**——它不仅说你错没错，还说「错得多没底气」；回归用**均方误差**。损失函数是模型的「价值观」：选什么 $\ell$，模型就优化什么；
3. **$\mathbb{E}$（期望）**：理论上要在**真实分布**上求平均，但我们只有一份样本——于是用**训练集上的平均损失（经验风险）**代替。样本越少、噪声越大，这个代替越不可靠，训练损失与真实期望损失的差距（泛化鸿沟）越大。

用第六章贯穿的主线任务把它填实：用茅台 2024 真实日线预测次日涨跌。特征 $x$ = 8 个只用当天及之前信息的技术指标（5/10/20 日动量、20 日波动、RSI、MACD 柱、均线偏离、换手率），标签 $y\in\{0,1\}$ = 次日是否上涨，$\ell$ = 交叉熵，$f$ 的输出 = $P(y=1|x)$。整章后面所有课，都是在替这道最优化题回答一个问题：**怎么保证解出来的 $f$ 不是把 241 天的噪声背了下来**。

## ML 在量化管线里的位置：自动化「因子与策略构造」

前五章搭的管线是「数据 → 因子 → 策略 → 回测」。ML 不是平行于这条管线的新系统，而是**把「因子构造」和「策略构造」这两个最耗人力的环节自动化**：

- 第四章的**因子就是特征**，因子检验就是单变量模型的评估，IC/分层收益（p4-l3）在第六章会原样复用（p6-l7 用 IC 评估 ML 预测力）；
- 第四章的多因子**打分加权是线性 ML**，第六章把它一般化成非线性（p6-l4）；
- 标签（p6-l3）回答「预测什么」，特征（p6-l2）回答「用什么预测」，评估（p6-l7）回答「预测得准不准、赚不赚钱」。

所以第六章产出的不是一个孤立模型，而是一段**插入原管线的新引擎**：吃同样的真实行情，吐更好的信号，再交给第三章的回测框架去检验。ML 能替代的是「人脑想特征、想规则」，替代不了的是「真实数据 + 严谨回测」——这两个地基，前五章已经打好。

## 为什么金融里的 ML 这么难：四个前提同时不成立

ML 在图像、语音上成功的配方是：海量样本 + 稳定规律 + 明确答案。金融数据把配方里的每一条都破坏了：

1. **信噪比极低**。茅台 2024 年日收益的标准差约 1.74%（真实，官方口径），而其中能被技术特征系统解释的部分只是很小一块——第四章真实测算里，PE 因子的月度 Rank IC 均值仅 0.016（p4 主线）。模型在金融里是在「含噪信号」里找「微弱信号」，和在清晰的猫照片里找猫，难度不是一个量级；
2. **非平稳**。图像规律几十年不变，市场结构每几年就换一次：风格切换、因子拥挤（p4-l5）、策略失效（p3 的样本外陷阱）——十年前有效的特征组合今天可能已经反转。模型学到的「规律」有保质期；
3. **样本有限，且有效的更少**。A 股单只股票一年只有约 242 个交易日（茅台 2024 主线数据），十年日线也不到三千个样本；更要命的是，20 日动量这类重叠窗口特征让相邻样本**高度自相关**——表面 242 个样本，真正独立的信息量远小于此。机器学习教科书动辄十万、百万样本的「大数定律保障」，在这里缩水得厉害；
4. **没有干净的答案与实验**。图像有确定的 ground truth（这是猫），金融没有「如果当初买了会怎样」的对照组；你只能在一个发生过一次的市场上反复回测，而回测本身就可能是拟合（多重检验，p3-l5）。

把这四条合起来，就是本章反复出现的那句冷水：**模型在训练集上漂亮 ≠ 在测试集上赚钱**。图像识别做到 99% 准确率是常规操作，A 股方向预测做到 55%（且稳定）就值得严肃对待——不是因为金融 ML 的人更笨，而是目标与数据性质根本不同。也正因如此，第六章用真实 A 股数据、按时间顺序切分、只用一次测试集——把每一条「自欺」的路都提前堵上。

## 本章地图与学完自检

第六章的路径是一个完整的「预测流水线」，每一课负责一个环节：

1. **特征工程**（p6-l2）：把行情变成 $x$——构造、去极值、标准化；
2. **标签设计**（p6-l3）：把「想预测的东西」变成 $y$——前瞻收益、分类阈值；
3. **模型选择**（p6-l4）：选 $f$ 的容量——线性、树模型、非线性；
4. **过拟合防范**（p6-l5）：防止把噪声背下来——切分、验证、正则；
5. **深度与强化**（p6-l6）：LSTM、强化学习框架，以及它们为什么更难；
6. **评估与挖掘**（p6-l7）：用 IC 与分类指标检验，形成可复用的 alpha 挖掘流程；
7. **阶段产出**（p6-l8）：ML 策略 vs 双均线 vs 买入持有，同一口径对比。

学完这一课，用三问自检：

- **为什么说 ML 是「规则来源光谱」的延伸而不是新的世界观？**（答不出 → 回看光谱表：因子打分已经是带一个特征的监督模型）
- **三类范式的分水岭是什么？评估各看什么？**（答不出 → 回看反馈来源一段）
- **金融数据哪四条特性让 ML 更难？「有效样本小于表面样本」指的是什么？**（答不出 → 回看四条特性，尤其第 3 条的重叠窗口例子）

**练习 2（选择题）：** 规则来源光谱的连续性。

:::quiz
Q: 把「单因子检验（第四章）」放进规则来源光谱，最准确的说法是?
- 它是与机器学习完全无关的统计工具
- 它本质上是带单一特征 $x$ 的监督模型，机器学习是这条光谱的延伸
- 它是无监督学习
- 它不需要任何数据
A: 2
E: 因子打分 $f(x)$ 有特征、有输出、有评估（IC/分层），就是单一特征的监督模型；ML 只是把特征变多、函数变复杂、权重交给最优化。

- 学习信号（反馈）来源：正确答案 / 数据结构 / 延迟奖励
- 是否使用 Python
- 数据量大小
A: 2
E: 监督看标签（正确答案），无监督看数据内部结构，强化看多步之后的累计奖励——反馈来源决定你该怎样评估模型。

:::quiz
Q: 强化学习在量化里最自然的应用位置是?
- 预测次日涨跌
- 仓位与执行决策（多步决策、延迟奖励）
- 因子去极值

**练习 5（选择题）：** 损失函数的角色。

:::quiz
Q: 说「损失函数是模型的价值观」是因为?
- 损失函数决定模型参数的初始值
- 模型优化的正是损失函数——选什么 $\ell$，模型就为它最小化什么
- 损失函数决定数据量
- 损失函数是 Python 里的内置函数
A: 2
E: $\min_f\mathbb{E}[\ell(y,f(x))]$ 里 $\ell$ 定义「错多少」；分类选交叉熵、回归选均方误差，选错 $\ell$ 等于让模型优化错误的目标。
:::

**练习 6（选择题）：** 经验风险与期望损失的差距。

:::quiz
Q: 用茅台 2024 约 241 个交易日样本估计期望损失 $\mathbb{E}[\ell(y,f(x))]$，下列哪个说法正确?
- 只要训练损失足够小，期望损失就一定小
- 样本量越大经验估计越接近期望损失；241 个日样本的估计方差很大
- 241 个样本足以精确估计期望损失
- 经验估计总是高估期望损失
A: 2
E: 训练集损失只是期望损失的经验估计；样本越少、噪声越大，训练损失越容易偏乐观，这正是金融 ML 低样本高噪音的根源。
:::

**练习 7（选择题）：** 重叠窗口特征与有效样本。

:::quiz
Q: 用 20 日动量作为特征预测次日涨跌，样本表面有 241 个日观测，下列说法正确的是?
- 241 个观测彼此完全独立
- 重叠窗口使相邻样本高度自相关，有效信息量远小于表面样本量
- 重叠窗口使样本量翻倍
- 动量特征与样本独立性无关
A: 2
E: 相邻日期的 20 日动量共享 19 天数据、高度相关——「表面 241 个样本」的有效独立信息远小于此，低估这一点是金融 ML 过拟合的常见入口。
:::

**练习 8（选择题）：** 金融与图像数据难度的差异。

:::quiz
Q: 为什么金融里 55% 的方向准确率已值得研究，而图像识别追求 99%?
- 因为金融数据格式更复杂
- 因为金融数据信噪比极低、非平稳、样本有限且无干净答案，目标与数据性质完全不同
- 因为金融从业者水平更低
- 因为方向准确率没有意义
A: 2
E: ML 在图像上成功的配方（海量 i.i.d. 样本 + 稳定规律 + 明确答案）在金融里每一条都不成立——评价标准必须跟着目标走。

**练习 9（应用题）：** 把监督学习映射到茅台主线任务。

:::exercise
T: 前五章构建了「数据 → 因子 → 策略 → 回测」管线。请把「用贵州茅台 SH600519 2024 真实日线构造 8 个技术特征，预测次日涨跌」这个任务，对照监督学习形式化 $\min_f\mathbb{E}[\ell(y,f(x))]$，说明：特征 $x$ 是什么、标签 $y$ 是什么、损失函数 $\ell$ 用分类的哪一类、模型 $f$ 的输出是什么。

追问一：若改为回归「预测次日收益率数值」，$\ell$ 与 $f$ 的输出各变成什么？

追问二：训练集损失只是 $\mathbb{E}[\ell(y,f(x))]$ 的经验估计——在低信噪比、样本只有 241 天且特征重叠的情况下，用它估计期望损失为什么容易偏乐观？

追问三：若进一步用**无监督**方式把 5000 只 A 股按风格聚成 10 组，再在组内做动量选股——这里聚类（无监督）与选股模型（监督）的分工是什么？各用什么信号评估？

:::answer
- **主答**：特征 $x$=8 个技术特征（5/10/20 日动量、20 日波动、RSI、MACD 柱、均线偏离、换手率，全部只用 $t$ 及之前信息）；标签 $y\in\{0,1\}$=次日涨跌；$\ell$=交叉熵；$f$ 输出=次日上涨概率 $P(y=1|x)$。
- **追问一**：$\ell$ 换均方误差（MSE），$f$ 直接输出收益率数值——分类给概率、回归给数值，损失的「价值观」随之改变。
- **追问二**：训练损失是在同一段样本上最小化后的残差，模型把这段的噪声也拟合进去；样本越少、信噪比越低、特征越重叠，「背噪声」的收益越大，训练损失与真实期望损失的泛化鸿沟越大。对策是时间切分 + 验证集（p6-l5）。
- **追问三**：聚类用「组内是否同质、组间是否可分」评估（无标签、无正确答案），它只负责把股票分组、降低选股搜索空间；选股模型用「组内预测是否准确、组合是否赚钱」评估（有标签）。两类范式的反馈来源不同，评估标尺必须分开——不能拿聚类的「稳」去替代选股的「准」。
:::

T: 某研究者在茅台 2024 真实日线上训练了一个含 200 个特征的模型，训练集方向准确率 99%，据此宣称「ML 能预测茅台次日涨跌」。请用本课四条特性逐条诊断这个结论哪里不可信，并指出至少两条可能造成 99% 的机制。

:::answer
- **机制来源**：① 200 个特征在 241 个样本上拟合，容量远大于样本——模型可以把每一天的噪声都背下来（记忆而非泛化）；② 若特征混入未来信息（前视偏差）或标签用错口径，准确率会虚高；③ 重叠窗口让相邻样本近重复，「训练 99%」可能只是记住了昨天的答案。
- **四条诊断**：信噪比极低——茅台日波动 1.74% 量级里真信号很弱，99% 已违反「金融里 55% 就难得」的常识；非平稳——即使真有规律也保质期有限，何况单年样本无法验证；样本有限且有效更少——241 个重叠样本撑不起 200 个特征；无干净答案——没有对照组，回测本身的拟合就可能制造 99%。结论：先按 p6-l5 的时间切分与验证集重测，再看样本外还有多少。
:::
:::

## 本章生态：ML 量化的工具与平台生态

- **经典工具箱**：scikit-learn（逻辑回归/树/聚类/PCA，教学与基线首选）、XGBoost/LightGBM（表格数据梯度提升树，量化特征预测的主力）、PyTorch/TensorFlow（神经网络与 LSTM）；
- **量化 ML 平台**：Microsoft Qlib（A 股数据 + 因子 + 模型 + 回测一体的开源平台）、聚宽/米筐的 ML 模块（国内数据与回测闭环）——本课程用真实 A 股数据手写轻量实现，是为了看清每层在做什么，换到这些平台时才不会被黑盒骗到；
- **数据现实**：任何 ML 模型的输入都只是行情与基本面（本课程数据源）；要引入另类数据（新闻、卫星、资金流）属于更前沿的领域，但「特征决定上限」的道理不变——模型只是把特征里的信号榨干，榨不出不存在的信号。
