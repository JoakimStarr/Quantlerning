## 完整 pipeline

量化投资是一条链，任何一环断裂，整体失效：

```
数据获取 → 因子/特征 → 策略/模型 → 组合配置 → 风险控制 → 执行/实盘
（第1章）   （第3/5章）   （第2/5章）    （第6章）    （第6章）   （第6章）
```

- **数据**：真实行情（第一章贯穿主线茅台，quantlab 库）；
- **因子**：单因子检验与多因子合成（第三章，161 个真实因子）；
- **策略**：传统规则（第二章）与 ML 模型（第五章，逻辑回归/梯度下降）；
- **组合**：马科维茨有效前沿、风险平价、Black-Litterman 观点融合（第六章）；
- **风控**：止损、压力测试、仓位管理（第六章）；
- **执行**：模拟盘验证 → 实盘上线（第六章）。

## 组合层的作用

第六章的三种组合方法解决不同问题：

- **马科维茨**：给定收益预测，找到最优分散化（依赖 $\mu$ 估计）；
- **风险平价**：不预测收益，只均衡风险（稳健，适合无观点时）；
- **Black-Litterman**：在均衡基础上融入观点（把预测与纪律结合）。

第五章的 ML 预测正可作为组合的**收益输入**：预测准 → 马科维茨/BL 有意义；预测不准 → 风险平价兜底。组合与预测共同决定最终配置。

## 风险控制是最后防线

第六章可视化已展示：止损限住最坏情况、压力测试揭示极端损失、仓位控制防止过度集中。**回测收益是「理论值」，风控决定「实际值」**——这是从模拟到实盘的分水岭。

## 全流程核查清单

- [ ] 数据真实、口径统一（复权、不含首日）
- [ ] 回测无前视偏差、成本已计入
- [ ] ML 模型过了交叉验证与时间切分
- [ ] 组合配置有明确依据（前沿/平价/BL）
- [ ] 止损、仓位、压力测试全部代码化
- [ ] 模拟盘稳定运行后才考虑实盘

## 结语

从「货币时间价值」到「实盘 pipeline」，六章走完了量化从 0 到 1 的完整路径。前几章的关键数字贯穿始终——茅台的复权收益、夏普、回撤；第五章学会了「模型有用 ≠ 策略赚钱」；第六章学会「回测能赚 ≠ 实盘能赚」。量化是一段持续学习的过程：**数据在变、市场在变，但纪律不变**——真实的检验，永远在样本之外。

## 练习题

**练习 1（选择题）：** 回测收益与实际收益的关系。

:::quiz
Q: 关于「回测收益 vs 实际收益」，正确的认识是？
- 回测收益就是实盘收益
- 回测收益是理论值，风控决定实际值
- 实际收益只取决于预测精度
- 风控只影响回撤、不影响收益
A: 2
E: 回测假设理想成交（收盘价/次日价、无冲击），实盘收益被执行成本与风控重新书写——「回测能赚 ≠ 实盘能赚」。
:::

**练习 2（选择题）：** 预测不准时的组合兜底方法。

:::quiz
Q: ML 预测准确率不高且没有明确观点时，第六章推荐用什么方法作为组合配置的稳健兜底？
- 马科维茨有效前沿
- Black-Litterman
- 风险平价
- 集中持仓
A: 3
E: 风险平价不依赖收益预测、只均衡风险，适合无观点时作为基准；预测可信时再用马科维茨/BL 融入收益信息。
:::

**练习 5（选择题）：** 未复权价格计算收益的偏差。

:::quiz
Q: 用未复权（不复权）价格序列计算某只分红股票的 2024 年收益，最可能的影响是？
- 没有任何影响
- 除权日出现虚假「下跌」，计算出的收益被低估
- 收益被系统性高估
- 只影响波动率、不影响收益
A: 2
E: 除权除息日价格下调但持股价值不变（现金红利 + 股价），未复权序列在除权日呈现假跌。官方口径要求复权连乘、不含首日（全流程核查清单第 1 条），否则收益与回测结论失真。
:::
