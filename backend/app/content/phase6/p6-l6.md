> **前置知识：** p6-l1~l5 基础（特征/标签/模型/过拟合）；p5-l1 随机过程。
> **学完能做什么：** 理解 LSTM 门控机制与 RL 三要素在交易中的对应，知道深度模型在金融低信噪比下的失效原因。

## 定义

时间序列预测：给定过去 $L$ 个时刻的观测 $[x_{t-L+1},\dots,x_t]$，预测未来 $h$ 步 $x_{t+h}$。与横截面模型（每行一个独立样本）不同，时序样本天然有序且自相关。

强化学习（Reinforcement Learning）的目标是学一个策略 $\pi$：给定状态 $s$ 输出动作 $a$，最大化长期累积奖励。

$$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$$

其中 $\gamma \in (0,1)$ 是折扣因子——越远期的奖励越打折。与监督学习（有标签，单步修正）不同，RL 的反馈是**延迟且稀疏**的：动作的后果要在多步之后才显现。

## RNN 与 LSTM

时间序列怎么建模？最经典的工具是循环神经网络（RNN）——它按时间步共享权重，把历史压缩进隐藏状态 $h_t$：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

普通 RNN 在长序列上梯度消失/爆炸。LSTM 引入**门控**：输入门、遗忘门、输出门控制信息流的保留与丢弃，从而学习长期依赖。

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$

遗忘门 $f_t$ 决定上一时刻记忆 $C_{t-1}$ 保留多少。门控让 LSTM 能记住数周前的市况，理论上优于固定窗口的 AR/MA 模型。

「为什么门控能救 RNN」的答案，藏在梯度消失的数学里：

:::viz gradient_vanishing caption=梯度消失演示（纯数学可视化）：蓝色为隐藏状态 $h_t$ 沿时间步的演化，红色为反向传播梯度（每步乘 $\tanh'(h_{t-1})\le1$ 的连乘）。红色曲线随步数指数衰减——这就是普通 RNN「记不住长期信息」的数学来源。
:::

先看**红色曲线的衰减速度**：时间步从 1 走到 10（滑块可拖到 20），梯度从 1 一路指数下滑，最后几步趋近 0——「连乘必缩」是 $\tanh' \le 1$ 的必然结果。再**拖时间步 L 滑块**：L 越大，红色曲线衰减得越彻底——序列越长，远时间步的梯度越接近 0，参数几乎学不到更新。最后注意蓝色 $h_t$ 的演化：它收敛到 0 附近，说明隐藏状态本身也在「遗忘」早期的信息。这正是 LSTM 门控要解决的问题：**把连乘路径变成可调的加法路径**，让梯度能「走」到远时间步。

## 为什么金融时序难

深度模型在语音、机器翻译上大放异彩，但一放到金融时序上就频频失灵，原因有四：

- **非平稳**：收益分布的均值、方差随市况漂移（p1-l8 波动聚集），训练时学到的统计规律会失效；
- **低信噪比**：可预测成分远小于噪音，模型容易把噪音当信号；
- **样本少**：10 年日线仅约 2400 个样本，深度模型参数远多于样本 → 严重过拟合；
- **重叠标签**：多步预测标签高度相关，独立同分布假设崩塌。

## RL 三要素在交易中的对应

强化学习的三要素，套到交易上就是：

- **状态 $s$**：持仓、资金、行情特征（技术指标、因子暴露）；
- **动作 $a$**：加仓、减仓、清仓、持仓不变；
- **奖励 $r$**：账户收益、风险调整后收益（如 Sharpe 增量）。

三要素的「循环」是 RL 区别于监督学习的核心：状态 → 动作 → 环境反馈 → 新状态。下面的演示把真实茅台 2024 日线当成「环境」，用三种示意策略跑这个循环：

:::viz rl_trading_loop caption=RL 交易循环演示（真实茅台 2024 日线，示意动作策略，非真实 RL 训练）：状态 = 过去 N 日均收益，动作 = 仓位（满仓/空仓），奖励 = 当日策略收益。切换「动量/反转/随机」三种策略看不同行为导致的不同净值；Lookback 滑块改变状态的敏感度。
:::

先看**三个策略按钮对应的净值差异**：动量（过去 N 日均涨则满仓）与反转（过去 N 日均跌则满仓）在 2024 年表现不同——同一环境、同一奖励定义，不同的「策略」给出不同结果，这正是 RL 要搜索的东西：$\pi(a|s)$。再**拖 Lookback 滑块**：它改变「状态」的敏感度——Lookback 大则状态迟钝、信号滞后，Lookback 小则状态敏感、交易频繁。最后注意**奖励 = 仓位乘当日涨跌**：当日满仓且上涨，奖励为正；空仓则奖励为 0——「奖励定义决定行为」在这张图里就是「策略决定哪些日子有奖励」。真实 RL 用策略梯度反复试错优化 $\pi$，本图只演示三要素的循环本身。

## 动手实验：两个演示各回答一个问题

**实验 1（门控到底救了什么）**：在梯度消失演示里把时间步 L 拖到 20，记下红色梯度曲线在第 10 步和第 20 步的量级（约 $0.4^{10}\approx10^{-4}$ 与 $0.4^{20}\approx10^{-8}$）。问：**如果损失主要来自第 20 步的信息，参数还能学到东西吗？** 这解释了普通 RNN「记不住」的根源——不是学得慢，是远端梯度小到没有学习信号（LSTM 门控把连乘改加法后才能传到远端）。

**实验 2（奖励定义如何改写行为）**：在 RL 交易循环里切换「动量 / 反转 / 随机」三种策略，对比净值。同一环境（茅台 2024）、同一奖励定义（当日仓位×涨跌），不同策略给出完全不同的结果——**RL 搜索的对象就是这个 $\pi(a|s)$**。再把 Lookback 从 5 拖到 20：状态变迟钝、切换变少。问：**奖励不变而状态定义改变，最优策略会不会变？**（会——状态是策略的输入，改状态等于改问题本身。）

## 训练机制

智能体通过「试错」改进：策略 $\pi(a|s)$ 给出每个状态下动作的概率，用策略梯度或价值函数（如 DQN）估计长期价值，反复与环境交互（回测就是模拟环境）。马尔可夫性质假设状态包含了决策所需的全部历史信息。

## 金融应用与挑战

LSTM 常被用于：短期价格/波动率预测、特征提取（把序列压成向量再喂给表格模型）、交易信号生成。但大量实证表明：**在 A 股日频，简单的线性/树模型加好特征，往往与 LSTM 相当甚至更优**，且可解释、易维护。深度时序模型的价值更多在分钟级高频与多资产组合层面。

RL 被用于：仓位管理、执行交易（最优执行）、多资产组合动态调整。

**实盘挑战**：
- **稀疏奖励**：交易日之间收益噪音大，奖励信号微弱且延迟；
- **非平稳环境**：市场机制变化让「学到的策略」快速失效；
- **回测过拟合**：RL 策略参数多，在回测中很容易「记住」历史路径；
- **探索 vs 利用**：探索新策略可能亏钱，实盘中风险不可控。

## 与本章的关系

LSTM 与 RL 都是模型选择（p6-l4）的一员——选择它们意味着接受高复杂度、高参数、弱可解释。第六章的可视化全部用轻量模型完成教学，因为**过拟合、标签设计、评估这些核心概念与模型复杂度无关**：在简单模型上学会的诊断能力，能直接迁移到任何深度模型。

RL 是第六章的最前沿，也是实盘落地最困难的。核心思想（状态、动作、奖励、策略梯度）与监督学习一脉相承：特征即状态、模型即策略、损失即负累积奖励。**在把 RL 用于实盘前，先把本章前五课的基础打牢**——标签设计、过拟合防范，在 RL 里同样成立且更严苛。

## 练习题

**练习 1（选择题）：** LSTM 相比普通 RNN 的核心改进。

:::quiz
Q: LSTM 相比普通 RNN 的核心改进是?
- 增加了更多层数
- 用门控机制控制信息流的保留与丢弃，缓解梯度消失
- 不再使用任何激活函数
- 固定窗口大小为常数
A: 2
E: 普通 RNN 在长序列上梯度消失/爆炸；LSTM 用输入门、遗忘门、输出门控制信息流，从而学习长期依赖。
:::

**练习 2（选择题）：** 折扣因子 γ 的作用。

:::quiz
Q: 累积奖励 $G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k}$ 中，折扣因子 $\gamma\in(0,1)$ 的含义是?
- 越远期的奖励越打折，智能体更看重近期
- 越远期的奖励被放得越大
- 表示市场波动率
- 表示动作空间大小
A: 1
E: $\gamma$ 对远期奖励打折——越远期的奖励在累积和中权重越小，智能体更看重近期收益。
:::

**练习 3（应用题）：** 手算一步 RNN 隐藏状态更新，体会梯度消失的来源。

:::exercise
T: 某 RNN 的隐藏状态更新为 $h_t=\tanh(W_h h_{t-1}+W_x x_t+b)$。设 $h_{t-1}=[0.5,-0.5]$、$W_h=[0.5,0.5]$、$W_x=1$、$x_t=1$、$b=0$。请先计算 $z=W_h h_{t-1}+W_x x_t+b$，再查近似值 $\tanh(1)\approx0.762$ 给出 $h_t$。最后说明：若 $L$ 很大，为什么沿时间反向传播时梯度会消失（与 $\tanh'$ 的取值有关）？

追问：若把激活换成 ReLU（$h_t=\max(0,z)$），$z>0$ 时 $\partial h_t/\partial z$ 等于多少？为什么这种导数能缓解梯度消失（对比 $\tanh'(z)=1-\tanh^2(z)\le1$）？但 ReLU 在金融深度模型中又会带来什么风险（结合非平稳与样本少）？


:::answer
- **主答**：$z=W_h h_{t-1}+W_xx_t+b=0.5\times0.5+0.5\times(-0.5)+1=1.0$；$h_t=\tanh(1)\approx0.762$。$L$ 大时反向传播每步乘 $W_h\times\tanh'\le\tanh'(1)\approx0.42<1$，连乘 $L$ 步后梯度 $\approx0.42^L\to0$——远时间步几乎收不到更新信号（梯度消失）。
- **追问**：$z>0$ 时 $\partial h_t/\partial z=1$——导数恒 1，连乘不衰减，梯度能「原样」传到远时间步，缓解消失。但风险：① ReLU 单元「死亡」（大梯度使 $z$ 恒负、导数恒 0）在非平稳数据上更常见——分布漂移把激活推入死区且永不恢复；② 金融样本少（10 年日频约 2400 个），死亡单元+过参数化的组合极易把训练段噪声记死——「导数不衰减」同时也意味着**噪声的梯度也不衰减**，过拟合更凶。
:::
:::

**练习 4（应用题）：** 把仓位管理任务映射为 RL 三要素，并讨论奖励设计。

:::exercise
T: 请把「用强化学习做茅台的仓位管理」映射为 RL 三要素：状态 $s$、动作 $a$、奖励 $r$ 分别应定义为什么？若奖励直接设为每日账户收益，结合「稀疏奖励」概念说明交易日的收益噪音会带来什么问题；若改用风险调整后的奖励（如 Sharpe 增量）又有什么权衡？

追问：若状态 $s$ 只含当日行情特征而不含持仓与资金，策略 $\pi(a|s)$ 会犯什么错误（结合马尔可夫性质）？再构造一个「奖励=每日账户收益」可能诱发的不良行为（如追涨杀跌、频繁换手）场景，并说明风险调整奖励为何能缓解。


:::answer
- **主答**：状态 $s$=持仓、可用资金、行情特征（动量/波动/因子暴露）；动作 $a$={加仓、减仓、清仓、持有}；奖励 $r$=账户收益（或 Sharpe 增量）。直接用每日收益：奖励噪音极大（日收益几乎白噪声，p0-l1），智能体难以从「运气」里分辨「好坏动作」——稀疏且高噪的奖励让学习信号淹没。
- **追问**：状态缺持仓/资金 → 违反马尔可夫性质：同一行情下「满仓」与「空仓」应给不同动作，但策略看不到仓位，等于对风险敞口「失明」——回测里可能撞对，实盘连亏（本课练习 5）。不良行为示例：奖励=每日收益 → 追涨（涨了有奖励）+ 频繁换手博短期奖励 → 高换手成本吃光收益。风险调整奖励（如 Sharpe 增量、回撤惩罚）把「波动与回撤」写进目标：频繁换手的成本、追高的回撤都会扣分，引导策略在收益与风险间权衡。
:::
:::

**练习 5（选择题）：** RL 状态设计违反马尔可夫性质的后果。

:::quiz
Q: 用 DQN 训练仓位管理，状态 $s$ 只含当前行情特征、不含持仓与资金。agent 回测大赚、实盘连亏，最可能的原因是?
- 状态不含持仓与资金，马尔可夫性质不满足，同一行情下不同仓位应给出不同动作，策略「失明」
- 折扣因子 $\gamma$ 设得太小
- 回测与实盘的成交价格必然一致
- 动作空间太大，与状态无关
A: 1
E: 马尔可夫性质假设状态包含决策所需的全部历史信息；缺持仓/资金时策略对风险敞口失明。RL 实盘还叠加回测过拟合、非平稳与探索风险。
:::
