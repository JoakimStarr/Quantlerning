> **前置知识：** p6-l4/l5 模型与过拟合；p4-l3 单因子检验（IC 框架）。
> **学完能做什么：** 用精确率/召回率/IC 评估模型预测力，理解时间外评估铁律与多重检验陷阱，建立可复现的挖掘流程。

## 定义

评估必须区分两类错误：预测方向但实际下跌（假阳性），预测下跌但实际上涨（假阴性）。对交易而言，两类错误的成本不同。

Alpha 挖掘（Alpha Mining）指从海量候选特征中系统化地寻找有预测力的因子。传统人工挖掘靠领域知识与逐步检验；ML 挖掘把「构造特征 → 评估 → 选择」自动化，一次评估成百上千个候选。

把「评估」与「挖掘」放在一课，因为**挖掘的质量完全取决于评估的严谨**：候选因子没有可靠的评估框架，挖得再多也只是制造假阳性。

## 分类指标

以「预测涨 / 实际涨」为正面：

- **准确率（Accuracy）** = 全对 / 全部。类别不平衡时虚高（永远猜多数类）；
- **精确率（Precision）** = 预测涨且真涨 / 预测涨。衡量「信它做多时有多可靠」；
- **召回率（Recall）** = 预测涨且真涨 / 实际涨。衡量「抓到了多少上涨」；
- **F1** = 精确率与召回率的调和平均。

## IC：因子的评估语言

分类指标是「准确不准确」，因子评估还要看「排序对不对」。第四章已用 IC（信息系数）衡量因子预测力。ML 预测值 $\hat{y}$ 与真实收益 $r$ 的 **Rank IC**（斯皮尔曼相关）是同一件事：

$$\text{IC} = \text{corr}(\text{rank}(\hat{y}), \text{rank}(r))$$

IC 的均值、ICIR（IC 均值/标准差）、IC 胜率（IC>0 的期数占比）是三层评估。第六章 ML 模型的预测概率就是「因子」，用第四章的 IC 框架评估完全一致——**ML 与因子在评估层面是统一的**。挖掘流程（见下）对每个候选因子复用的正是这套 IC 框架。

## 时间外评估

金融评估的铁律：**测试集必须严格晚于训练集**（时间顺序切分），且测试集只用来评估一次。在测试集上反复调参 = 把测试集变成训练集（数据泄漏）。p6-l4 特征重要度图与 p6-l8 回测都用时间切分。

**先看三条净值曲线的相对位置**：在测试段（时间顺序切分），逻辑回归（ML）和双均线未必明显跑赢买入持有——这正是要传达的核心事实：**预测「准」和交易「赚」是两回事**。**再看绩效表的明细**：如果 ML 模型的准确率、IC 都好看，但净值表现一般，差异往往来自交易成本、持仓频率和信号延迟（p3-l7 的成本侵蚀）。**最后拖动阈值滑块**：阈值越高，信号越少但单次更准，你会在「次数」和「精确率」之间看到此消彼长——这是 p6-l7 评估语言（精确率/召回率）在交易上的直接体现。

## 挖掘流程

1. **特征生成**：对原始数据做变换（动量、比率、滚动统计、时序差分），组合成特征空间；
2. **评估**：每个候选算 IC / ICIR / 分层收益（第四章 p4-l3 的完整框架）；
3. **筛选**：按 IC 显著性、稳定性、换手、容量过滤；
4. **组合**：多因子合成（p4-l4）或直接作为 ML 特征（p6-l4）。

## 挖掘的过拟合陷阱

挖掘大量因子再选「IC 最高」的，是**选择偏差**（多重检验）的典型：

$$P(\text{至少一个假阳性}) = 1 - (1-\alpha)^N$$

$N$ 个独立候选、显著性水平 $\alpha=5\%$ 时，$N=100$ 就有 $99.4\%$ 概率至少出现一个假阳性。第四章的量化库里有 161 个因子，若逐一检验而不做多重检验校正，结论不可信。

## 金融应用

- 用 IC/ICIR 评估预测概率作为因子的单调性；
- 用精确率评估「当模型说涨时做多」的可靠性——低精确率 + 高换手 = 交易成本吞噬收益；
- 分类阈值（p6-l8 的阈值滑块）是精确率/召回率的权衡旋钮：阈值越高，只做高置信信号 → 精确率升、次数降；
- 本课程数据库里的 161 因子库就是「挖掘结果」的静态快照——本章教的是**如何自己生成与评估**；
- 机器学习让挖掘提速：特征重要度（p6-l4）自动给出候选排序；
- 实盘约束：挖掘出的因子必须过「样本外 + 成本 + 容量」三重检验才有价值。

## 与第四章的联系

p4-l5 因子挖掘讲流程，本章讲 ML 如何加速它。两者共享评估语言（IC/ICIR/分层收益），区别是候选集规模与自动化程度。**挖掘的意义不在「找到」而在「验证」**——本章的交叉验证（p6-l5）就是挖掘环节的质检工序。

## 练习题

**练习 1（选择题）：** 精确率的定义。

:::quiz
Q: 以「预测涨且实际涨」为真阳性，精确率的定义是?
- 预测涨且真涨 / 预测涨
- 预测涨且真涨 / 实际涨
- 全对 / 全部
- 预测跌且真跌 / 实际跌
A: 1
E: 精确率 = 预测涨且真涨 / 预测涨，衡量「信它做多时有多可靠」；召回率 = 预测涨且真涨 / 实际涨，衡量「抓到了多少上涨」。
:::

**练习 2（选择题）：** 多重检验下假阳性的概率。

:::quiz
Q: 显著性水平 $\alpha=5\%$、候选因子 $N=100$ 时，至少出现一个假阳性的概率约为?
- $5\%$
- $1-(1-0.05)^{100}\approx99.4\%$
- $0.05\%$
- $100\%$，与 $N$ 无关
A: 2
E: $P(\text{至少一个假阳性})=1-(1-\alpha)^N$，代入 $N=100,\alpha=0.05$ 得约 $99.4\%$。
:::

**练习 3（选择题）：** 在测试集上反复调参的数据泄漏。

:::quiz
Q: 研究员在同一个时间顺序切分的测试集上反复调参 50 次后，报告测试集准确率 72%。该数字可信吗?
- 可信，因为测试集是时间顺序切分的
- 不可信：反复在测试集上调参等于把测试集信息泄漏进模型选择，测试集实际已「被训练」
- 可信，因为 72% 明显高于随机
- 可信，只要报告的是准确率而非 IC
A: 2
E: 时间外评估铁律：测试集只用来评估一次；反复调参使测试误差被选择偏差压低，应另留独立测试段或嵌套交叉验证。
:::

**练习 4（应用题）：** 由混淆矩阵计算分类指标，并联系交易成本。

:::exercise
T: 某模型在时间顺序切分的测试段上预测茅台次日涨跌，得到混淆矩阵：预测涨且真涨 45 次、预测涨但实际跌 15 次、预测跌但实际涨 35 次、预测跌且真跌 55 次。请计算准确率、精确率、召回率与 F1，并说明：若把它当交易信号「模型说涨就做多」，精确率只有 75% 意味着什么？结合「低精确率 + 高换手 = 交易成本吞噬收益」讨论。

追问：若把分类阈值从 0.5 降到 0.3（更容易判「涨」），精确率与召回率分别会如何变化，这对应更激进还是更保守的交易？再考虑极端类别不平衡：某数据集 90% 为下跌、模型永远猜「跌」，准确率高达 90%——此时对「上涨」类的召回率是多少，为什么准确率在此处会误导？


:::answer
- **主答**：准确率 $=(45+55)/150=66.7\%$；精确率 $=45/60=75\%$；召回率 $=45/80=56.3\%$；$F1=2\times0.75\times0.563/(0.75+0.563)\approx64.3\%$。精确率 75% = 「模型说涨时，4 次里 3 次对」——当交易信号用，每 4 笔多单 1 笔亏损，还要叠加换手成本。
- **追问**：阈值 0.5→0.3：更多样本被判「涨」——召回率↑、精确率↓（抓得全但错得多），对应**更激进**（交易次数多、单笔质量降）。90% 猜「跌」的例子：对「上涨」类的召回率 $=0/10\%=0$——一次上涨都没抓到。准确率 90% 的误导：它被 90% 的多数类（下跌）撑起来，对真正想交易的「上涨」类毫无能力；类别不平衡下必须看分类别的精确率/召回率，而非整体准确率。
:::
:::

**练习 5（应用题）：** 计算多重检验假阳性概率，并讨论校正。

:::exercise
T: 你一次评估了 $N=50$ 个候选因子，显著性水平 $\alpha=5\%$。请用 $P(\text{至少一个假阳性})=1-(1-\alpha)^N$ 计算至少出现一个假阳性的概率（保留指数形式即可），并说明：为什么「挖 50 个因子取 IC 最高者」的结论不可信？可以采取哪些校正或验证手段来保护结论？

追问：若 $N$ 从 50 增到 200，概率变为 $1-0.95^{200}$——用 $0.95^{200}=e^{200\ln0.95}\approx e^{-10.26}$ 估算其近似值，并解释「候选越多、假阳性越接近必然」为什么反直觉；再讨论 Bonferroni 校正（每个因子阈值降为 $\alpha/N$）的代价：它会漏掉哪些因子（联系第二类错误）？


:::answer
- **主答**：$1-(0.95)^{50}\approx92.3\%$——挖 50 个取 IC 最高者，结论大概率是运气（p4-l5 同款计算）。校正手段：样本外验证、Bonferroni（$\alpha/50=0.001$）、报告全部候选的分布、分批确认。
- **追问**：$1-0.95^{200}=1-e^{200\ln0.95}=1-e^{-10.26}\approx99.997\%$——候选越多，「至少一个假阳性」越接近必然。反直觉点：直觉以为「挖得多=机会多」，统计上是「挖得多=假阳性必然多」——机会没变多，噪声的极值变大了。Bonferroni 代价：阈值 $\alpha/N=0.00025$（|t|≈3.6+）极严，真实但中等强度的因子会被漏掉——**第二类错误（漏检）上升**；所以实务组合拳是「样本外为主、校正为辅、报告分布」。
:::
:::
