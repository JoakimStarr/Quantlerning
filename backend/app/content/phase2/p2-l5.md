## 回测的定义

先给定义：回测（Backtesting）是在历史数据上模拟一段策略的完整生命——从信号生成、仓位映射、成交得价，到逐日净值累计。它回答一个问题——**「如果这套规则从过去跑到现在，结果如何？」**

**回测不能预测未来**。未来可能出现历史里没有出现过的情况（新的制度、新的市场结构），回测只能「排除明显站不住脚的想法」，不能保证未来盈利。它的价值在于：让后面的「看」和「疑」有对象——先跑出结果，再判断结果靠不靠得住。

回测的四个组成部分：

1. **数据**：真实历史行情（本课程用 quantlab 库，复权口径）；
2. **策略规则**：p2-l1 的信号 → 持仓 → 交易三段；
3. **撮合**：信号出现后按什么价格成交（本课程统一「次日开盘价」，避免前视）；
4. **绩效**：净值曲线与各项指标（p2-l6）。

## 朴素回测引擎

一个最小的回测引擎只需四个循环步骤，用真实茅台数据跑均线交叉：

```
初始化：cash = 首日资金，position = 0（空仓）
逐日循环：对每一天 t
    1. 由 t-1 收盘的均线关系计算今日信号
    2. 若持币且有买入信号 → 按今日开盘价买入
    3. 若持仓且有卖出信号 → 按今日开盘价卖出
    4. 用今日收盘价标记市值，记录净值
```

:::viz backtest_engine code=sh600519 start=2020-01-01 end=2026-08-10 caption=朴素回测逐日重放（真实茅台 2020-2026）：上图为金叉/死叉信号驱动下的持仓状态与成交点；下图净值曲线由「当日持仓 × 当日涨跌」逐日累计。每一步都可查、可复核。
:::

这个「初始化 + 逐日循环」的框架，正是聚宽教程里讲的**策略基本框架**——初始化做策略开始前的事（选标的、定参数），周期循环做每个周期的事（看信号、下单、记净值）。人的日常交易其实也符合这个框架：脑中的交易知识是「初始化」，每天看行情、判断、下单是「循环」。把投资灵感装进这个框架，才能让计算机执行。

## 本课程回测口径

为了让所有策略横向可比，本课程统一三个口径：

| 项目 | 约定 |
|---|---|
| 数据 | quantlab 真实日线，复权 pct_chg |
| 成交价 | 信号**次日开盘价**（当日看到信号当日成交即前视） |
| 收益口径 | 复利连乘、不含首日、ddof=1、几何年化 |

任何策略在本课程中的回测，都在这三个约定下进行。这也是第二章所有对比表格的数字来源。

> 注：策略信号（均线/动量/布林带）用**未复权收盘价**计算，与收益用的复权 pct_chg 口径不同——两者在分红除权日会有微小差异（除权日未复权价「跳跌」，可能诱发假信号）。这是本课程的教学简化口径，第一章 p1-l10 对技术指标有同样的说明。

## 回测引擎的进阶

真实引擎还需处理更多：涨跌停不可成交、停牌、最小交易单位、融资融券、滑点与佣金（p2-l7 专讲）。业界常用 Backtrader / vn.py / zipline 等框架，它们把「撮合」「成本」「绩效」抽象成可配置模块——但**框架只是工具，口径才是灵魂**。

一个回测结果是否可信，取决于你能回答三个问题：数据是否真实？成交是否可实际发生？指标口径是否统一？本课接下来的内容，讲回测最容易踩的坑。

## 回测的统计视角

回测得到的年化收益、夏普不是「确定值」，而是**样本估计**——它来自有限的一段历史，本身有误差。把策略日收益当成随机样本，统计量就有标准误：

$$SE(\text{年化收益})\approx\frac{\sigma_{ann}}{\sqrt{n/252}},\qquad SE(Sharpe)\approx\sqrt{\frac{1+Sharpe^2/2}{n}}$$

其中 $n$ 是回测天数。含义：

- 茅台 2020-2026 约 1600 个交易日，若策略年化波动 18%，年化收益的约 1 个标准误约 $18\%/\sqrt{1600/252}\approx7.1\%$——**±7 个百分点的波动，完全可能把 4.4% 的均线年化「变」成 11% 或 -3%**；
- 夏普的近似标准误 $SE(Sharpe)\approx\sqrt{(1+Sharpe^2/2)/n}$：夏普 0.2、1600 天时约 $\sqrt{1.02/1600}\approx0.025$，95% 置信区间约 ±0.05——夏普 0.20 与 0.15 在这段样本上几乎没有区分度。

**回测的统计结论**：样本越短，指标越不可信；「5.6% 年化」与「7.4% 年化」的差异，在 1600 天样本里可能只是噪声。所以：
- 永远报回测天数与日数（样本量）；
- 对比策略时看置信区间而非单个数字；
- 长样本（跨牛熊）比短样本可信，这也是第二章把窗口拉到 2020-2026 的原因。

## 训练集与测试集

回测的统计视角引出一个关键问题：**既然样本估计有噪声，如何知道策略是真的有效，还是只是在这段历史上碰巧有效？** 答案是把数据切成两段：

- **训练集（in-sample）**：用来「找」策略与调参数——比如扫描均线周期、确定 lookback 窗口；
- **测试集（out-of-sample）**：策略定稿之后，用这段「没见过」的数据做最终检验。

如果策略只在训练集上赚钱、一到测试集就失效，说明它学到的不是规律，而是训练集的噪声（过拟合，本课下文专讲）。**先猜后验、数据说了算**：训练集负责「猜」，测试集负责「验」——验证必须用没参与过调参的数据，否则就是「考自己出过的题」。

本课程的策略都是规则型的（均线、唐奇安、动量），没有显式的「训练」步骤，但同样的原则适用：不要在整段历史上反复调参直到好看为止，要留出样本外窗口检验。

## 前视偏差

第一类坑是**前视偏差**（Look-Ahead Bias）：把未来信息混进了历史决策。最常见的是成交时点——信号用 t 日收盘数据算出来，却假设 t 日收盘就成交；实际中盘后下单只能按 t+1 日价格成交。

本课程统一「信号次日开盘价成交」，就是为了消除这类偏差。

:::viz lookahead code=sh600519 start=2020-01-01 end=2026-08-10 caption=前视偏差演示（真实茅台）：✓ 用 t 日收盘信号、t+1 日成交（合规）；✗ 用 t 日收盘信号、t 日收盘价成交（前视——把「明天才知道的事」用在了今天）。两条净值曲线的差距就是前视偏差带来的虚假超额。
:::

同类陷阱还包括：用未来财报数据算历史 PE（p1-l11 的 PIT）、用全天高低价做日内止损（盘中不知道会触及）等。

## 幸存者偏差

第二类坑是**幸存者偏差**（Survivorship Bias）：只回测活到今天的标的。新股、退市股、长期暴跌股消失在样本里，回测就只剩下「赢家池」。

- 用今天还存活的股票回测 → 天然偏乐观；
- 用 index 成分股但用今天的最新成分 → 把 2018 年选股标准套用到 2026 年的名单上。

真实回测必须**逐期记录当时的入选名单**（point-in-time 的股票池），而不是用今天的名单回溯。

## 过拟合

第三类坑是**过拟合**（Overfitting）：参数对历史数据贴得太紧。任何策略都含参数（均线周期、z-score 阈值、lookback 长度），参数能「调出」漂亮的回测——但调出来的漂亮是对噪声的拟合：

- 参数越多，可调的维度越大，虚高越严重；
- 在历史上找最优参数再在该段回测，本身就是前视（用整段历史选参数，再在整段上评价）。

:::viz parameter_landscape code=sh600519 start=2020-01-01 end=2026-08-10 caption=参数热力图（真实茅台，均线交叉策略）：横轴慢线周期、纵轴快线周期，颜色为年化收益。亮色区域是「碰巧」好的参数——换个窗口可能完全变样。参数平面里存在大量孤立亮点，正是过拟合的温床。
:::

### 锯齿现象

把参数扫描的结果画成柱状图，常见的形态是一根根**锯齿**——相邻参数（如 MA10 与 MA11）的年化收益剧烈跳动，忽高忽低。锯齿是过拟合的直观证据：

- 如果参数从 10 到 12 收益从 +8% 跳到 -5% 再跳回 +9%，说明这些「好参数」是在**拟合噪声**，而不是捕捉规律；
- 真正的规律应该是**平滑的**：参数在合理范围内变化，收益随之平缓移动，而不是随机跳动。

**应对锯齿**：不要只盯「冠军参数」，要看**参数邻域**——冠军参数周围 ±20% 的邻居是否同样表现良好。锯齿越尖锐，冠军参数越不可信。

## 应对框架

回测结果可信的三个检验：

1. **样本外**：参数在 A 段定好，在 B 段（从没见过的数据）验证；
2. **换参数稳健**：最优参数附近 ±20% 依然成立才可信（热力图上是一条「脊」而不是一个「点」）；
3. **扣成本复算**：把佣金、滑点（p2-l7）加进去，还能剩多少。

**高原型 vs 山峰型**：稳健参数在参数平面上呈现两种地形——**高原型**（plateau）参数邻域内收益都高，说明规律真实；**山峰型**（peak）只有孤立的最高点，周围塌陷，说明那是噪声。山峰型参数换窗口就失效，高原型参数才经得起样本外检验。

记住：回测的目的不是证明策略好，而是**找出策略在什么条件下会失败**。一上来就漂亮的回测，通常意味着有坑没找到。

## 多重检验：试得越多，假阳性越多

过拟合还有一个更隐蔽的变体——**多重检验**（multiple testing）。设想你在回测 50 组均线参数、或试了 50 条不同的策略规则。每条规则的「真实」期望收益都是零（纯噪声），但只要试验次数足够多，**最好那一组**的统计量必然显著。

:::viz multiple_testing caption=多重检验演示（纯模拟示意）：每组策略的真实期望收益为零，但试验 N 组后「最优一组」的 |t| 统计量随 N 增大而上升。蓝色柱为模拟最优 |t| 的中位数（N=10/50/200 时约 1.84/2.47/2.92），红线为渐近近似 $\mathbb{E}[\max|Z|]\approx\sqrt{2\ln(2N)}$（对应约 2.45/3.04/3.46）——无论用哪种口径，试错次数一多，最优组的 |t| 就会越过 5% 显著线 1.96。这不是策略有效，而是「从 N 个噪声里挑最大」的必然结果。
:::

数学上，若每组的统计量服从标准正态，则 $N$ 组独立试验中最大绝对值的期望随 $N$ 增长，渐近约为 $\sqrt{2\ln(2N)}$。模拟验证（20000 次重复）：$N=10$ 时最优 |t| 中位数约 **1.84**，$N=50$ 约 **2.47**，$N=200$ 约 **2.92**——**全都超过 1.96 的「显著」线**。这不是统计方法的错，而是「在大量试验里挑最好」本身就制造显著。

**应对方法**：
1. **样本外**：参数/规则只在训练段内挑选，验证段从未参与选择——这是第一道防线；
2. **多重检验校正**：Bonferroni 把显著性阈值收紧为 $\alpha/N$（试 50 组就用 0.05/50=0.001），或记录「试了多少次」如实报告；
3. **对「调出来的最好」天然怀疑**：p2-l6 的「没有圣杯」就是这一原则的策略层表述。

- 用整段历史调参后，再在整段历史上评价策略，是有效的验证
- 测试集用于「找」策略与调参数，训练集用于最终检验
- 训练集用来调参数，测试集用「没见过」的数据做最终检验，防止把噪声当规律
- 训练集和测试集可以重叠使用
A: 3
E: 训练集负责「猜」（调参），测试集负责「验」——验证必须用没参与过调参的数据，否则等于考自己出过的题（信息泄露）。
:::

**练习 12（选择题）：** 前视偏差的识别。

:::quiz
Q: 下列哪种情况属于前视偏差?
- 用 t 日收盘信号、t+1 日成交
- 用 t 日收盘信号、t 日收盘价成交
- 用 t-1 日收盘信号、t 日开盘价成交
- 用 t-1 日收盘信号、t+1 日开盘价成交
A: 2
E: 前视偏差把未来信息混进历史决策：t 日收盘才能看到信号，t 日收盘就成交相当于把「明天才知道的事」用在今天。
:::

**练习 13（选择题）：** 幸存者偏差的定义。

:::quiz
Q: 幸存者偏差是指?
- 回测只覆盖活到今天的标的，退市股、暴跌股消失在样本里，结果偏乐观
- 用未来数据算历史指标
- 参数调得太紧
- 成交价偏离信号价
A: 1
E: 只回测「赢家池」天然乐观；正确做法是逐期记录当时的入选名单（point-in-time 股票池），而非用今天的名单回溯。
:::

**练习 14（选择题）：** 幸存者偏差的识别。

:::quiz
Q: 用 2026 年「今天仍存活的股票名单」回测 2018-2026 的选股策略，主要引入的是?
- 前视偏差
- 幸存者偏差
- 交易成本
- 数据缺失
A: 2
E: 退市股、长期暴跌股已不在今天名单里，只回测「赢家池」天然偏乐观；应逐期记录当时的入选名单（point-in-time 股票池）。
:::

**练习 15（选择题）：** 「全段选参 + 全段评价」的问题。

:::quiz
Q: 为什么「在历史上找最优参数、再在该段历史评价」本身是前视?
- 因为参数越多计算越慢
- 因为用整段历史选参数、再在整段上评价，等于把样本内当样本外
- 因为参数必须是整数
- 因为均线周期不能超过 200
A: 2
E: 用整段历史选参数再在整段评价，把信息从「样本内」泄露到了「样本外」，本质上与前视同类。
:::

**练习 16（选择题）：** 「换参数稳健」的特征。

:::quiz
Q: 「换参数稳健」检验要求最优参数附近 ±20% 依然成立，其对应的直观特征是?
- 参数热力图上是一个孤立亮点
- 参数热力图上是一条「脊」而不是一个「点」
- 参数越多越好
- 只要样本内收益高即可
A: 2
E: 好参数周围应是整条「脊」而非孤立「点」——孤立亮点是对噪声的过拟合，换个窗口就会失效。
:::

**练习 17（选择题）：** 样本外检验的含义。

:::quiz
Q: 「样本外检验」是指?
- 在选参数用的同一段历史上再跑一遍确认
- 参数在 A 段定好，在从没见过的 B 段数据上验证
- 把参数取值范围扩大一倍
- 把回测区间延长一倍
A: 2
E: 样本外要求用「没见过」的数据验证；在样本内再跑一遍无法检验是否过拟合。
:::

**练习 18（应用题）：** 识别「全段选参 + 全段评价」的问题并设计正确流程。

:::exercise
T: 某人在茅台 2020-2026 全段上遍历均线快慢参数（快线 5~50、慢线 40~200），找出年化收益最高的一组（快 17、慢 43，年化 9.8%），随后直接报出这段 9.8% 的年化收益。请指出该做法的两处问题（分别对应哪类偏差），并设计一个正确的评估流程。

（追问）若按你的流程在 B 段验证后，最优参数附近 ±20% 的年化收益从 9.8% 跌到 3%，你会认为该策略稳健吗？「±20% 稳健」在参数热力图上的直观形态是「脊」还是「点」？为什么？

:::

**练习 19（选择题）：** 多重检验的虚假显著。

:::quiz
Q: 在 50 组期望收益为零的随机策略里挑出表现最好的一组，其 |t| 统计量通常?
- 仍小于 1.96，不会显著
- 会超过 1.96，但这不是策略有效，而是「从大量噪声里挑最大」的多重检验结果
- 恰好等于 0
- 与试验组数无关
A: 2
E: 渐近公式 $\mathbb{E}[\max|Z|]\approx\sqrt{2\ln(2N)}$ 对 $N=50$ 约 $3.0$，蒙特卡洛模拟中位数约 $2.5$，均已超 $1.96$ 显著线；这是「从大量噪声里挑最大」制造出的虚假显著，须用样本外与多重检验校正应对。
:::

**练习 20（应用题）：** 多重检验的假阳性估算。

:::exercise
T: 某人在回测里试了 100 条随机策略规则，从中挑出夏普最高的那条（样本内 Sharpe 1.9）。请说明：若每条策略的真实夏普都是零（纯噪声），试 100 条后「最好那条」的 |t| 统计量大约会落在什么水平？这超过 1.96 的 5% 显著线了吗？这说明了什么，正确的做法是什么？

（追问）若按 Bonferroni 把显著性阈值收紧到 $\alpha/N=0.05/100=0.0005$（对应 |t| 约 3.48），上面「最优那条」约 2.70 的 |t| 还能通过吗？为什么 Bonferroni 在策略搜索中偏保守？

:::

**练习 22（选择题）：** 两类偏差的叠加识别。

:::quiz
Q: 某回测用「2018 年已上市、且今天仍存活的股票名单」做历史选股样本，并按信号当日收盘价成交。该回测至少包含?
- 只有幸存者偏差
- 幸存者偏差 + 前视偏差
- 只有前视偏差
- 两类偏差都没有
A: 2
E: 用今天存活名单回测历史=幸存者偏差（退市股被剔除）；t 日收盘信号当日成交=前视偏差（把 t 日收盘信息用于 t 日）。二者都违反 point-in-time 原则。
:::

**练习 23（选择题）：** 锯齿现象。

:::quiz
Q: 参数扫描的年化收益柱状图呈现剧烈锯齿（MA10=+8%、MA11=-5%、MA12=+9%）。这说明?
- 冠军参数 MA10 一定是最优选择
- 相邻参数收益剧烈跳动，说明「好参数」在拟合噪声而非捕捉规律，冠军参数不可信
- 参数越少锯齿越严重
- 锯齿说明策略有前视偏差
A: 2
E: 真正的规律应让参数邻域收益平滑移动；锯齿越尖锐说明参数在拟合噪声，应看参数邻域而非孤立冠军。
:::

**练习 24（选择题）：** 高原型与山峰型。

:::quiz
Q: 参数平面上「山峰型」（peak）参数的特征是?
- 参数邻域内收益普遍较高，规律真实
- 只有孤立的最高点、周围塌陷，换窗口就失效，说明那是噪声
- 山峰型参数比高原型更稳健
- 山峰型参数不需要样本外验证
A: 2
E: 高原型邻域收益都高=规律真实；山峰型只有孤立高点=拟合噪声，换窗口就失效，必须用样本外检验。
:::
